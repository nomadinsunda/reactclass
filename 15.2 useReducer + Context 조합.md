`useReducer` + `Context` 조합은 **Redux 없이도 구조적이고 확장 가능한 상태관리 시스템**을 React 내부에서 구현할 수 있는 강력한 패턴입니다.

이번엔 이를 바탕으로 **실전 예제**를 하나 만들어드리겠습니다.

---

# 🧠 목표

> ✔️ 전역 상태로 사용자 목록 관리
> ✔️ `useReducer`로 액션 기반 상태 전이
> ✔️ `Context`로 어디서든 접근 가능
> ✔️ 컴포넌트는 `useContext`만으로 상태/디스패치 사용

---

## ✅ 1. `UserContext.jsx`

```tsx
import { createContext, useContext, useReducer } from 'react';

// 🧩 상태 초기값
const initialState = {
  users: []
};

// 🧩 액션 기반 reducer
function userReducer(state, action) {
  switch (action.type) {
    case 'ADD_USER':
      return { users: [...state.users, action.payload] };
    case 'REMOVE_USER':
      return { users: state.users.filter(u => u.id !== action.payload) };
    default:
      throw new Error(`Unhandled action: ${action.type}`);
  }
}

// 🧩 Context 생성
const UserStateContext = createContext();
const UserDispatchContext = createContext();

// 🧩 Provider 컴포넌트
export function UserProvider({ children }) {
  const [state, dispatch] = useReducer(userReducer, initialState);

  return (
    <UserStateContext.Provider value={state}>
      <UserDispatchContext.Provider value={dispatch}>
        {children}
      </UserDispatchContext.Provider>
    </UserStateContext.Provider>
  );
}

// 🧩 커스텀 훅: 상태 구독
export const useUserState = () => {
  const context = useContext(UserStateContext);
  if (!context) throw new Error('useUserState must be used within UserProvider');
  return context;
};

// 🧩 커스텀 훅: 디스패치 구독
export const useUserDispatch = () => {
  const context = useContext(UserDispatchContext);
  if (!context) throw new Error('useUserDispatch must be used within UserProvider');
  return context;
};
```

## ✅ 2. `UserList.jsx` (전역 상태 읽기)

```tsx
import { useUserState } from '../context/UserContext';

function UserList() {
  const { users } = useUserState();

  return (
    <ul>
      {users.map(user => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
}

export default UserList;
```

## ✅ 3. `UserControls.jsx` (전역 상태 수정)

```tsx
import { useUserDispatch } from '../context/UserContext';

function UserControls() {
  const dispatch = useUserDispatch();

  const addUser = () => {
    const newUser = {
      id: Date.now(),
      name: `User ${Math.floor(Math.random() * 100)}`
    };
    dispatch({ type: 'ADD_USER', payload: newUser });
  };

  const removeUser = () => {
    dispatch({ type: 'REMOVE_USER', payload: prompt('삭제할 ID 입력') });
  };

  return (
    <div>
      <button onClick={addUser}>+ 사용자 추가</button>
      <button onClick={removeUser}>– 사용자 삭제</button>
    </div>
  );
}

export default UserControls;
```

## ✅ 4. `App.jsx`

```tsx
import { UserProvider } from './context/UserContext';
import UserList from './components/UserList';
import UserControls from './components/UserControls';

function App() {
  return (
    <UserProvider>
      <h1>👥 사용자 목록</h1>
      <UserControls />
      <UserList />
    </UserProvider>
  );
}

export default App;
```

# ✅ 장점 요약

| 항목               | 효과                     |
| ---------------- | ---------------------- |
| `useReducer`     | 상태 전이를 액션 중심으로 깔끔하게 구성 |
| `Context`        | 전역으로 상태/dispatch 공유    |
| 분리된 커스텀 훅        | 코드 재사용, 테스트 용이         |
| Redux 없이도 구조적 관리 | 작은 앱에 매우 적합한 상태관리 솔루션  |

## 📘 확장 가능성

* **복수 Context로 모듈화 가능** (`UserContext`, `ThemeContext`, 등)
* **비동기 작업 도입**: dispatch + `useEffect` or `custom hook`
* **TypeScript로 타입 안전한 액션/상태 정의**
* **React DevTools의 Context 디버깅도 가능**
