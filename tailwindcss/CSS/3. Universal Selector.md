# 🌟 CSS Universal Selector(`*`) 완벽 가이드

CSS를 작성하다 보면 **"모든 요소에 동일한 스타일을 적용하고 싶다"** 는 순간이 옵니다.
이럴 때 딱 맞는 선택자가 바로 **Universal Selector**, 즉 `*` 입니다.


---

## 1. 📖 Universal Selector란?

Universal Selector는 CSS에서 **모든 HTML 요소**를 선택하는 선택자입니다.
문법은 정말 간단합니다.

```css
* {
  /* 모든 요소에 적용할 스타일 */
}
```

예시 📝:

```css
* {
  margin: 0;
  padding: 0;
}
```

💡 위 코드는 **모든 요소의 margin과 padding을 0으로 초기화**합니다.

---

## 2. 🧐 특징

### 🔹 2.1 모든 요소를 선택

* HTML의 모든 태그(`html`, `body`, `div`, `p`, `span`, `a` 등)에 적용됩니다.

### 🔹 2.2 범위 제한 가능

* 단독 사용 시 **문서 전체**를 선택하지만, 다른 선택자와 결합해 **특정 영역**만 선택할 수도 있습니다.

```css
article * {
  color: #333;
}
```

📌 위 코드는 `<article>` 안에 있는 모든 요소의 글자색을 `#333`으로 설정합니다.

### 🔹 2.3 우선순위(Specificity)

* **Specificity 값:** `0,0,0,0` ➡ CSS에서 가장 낮음.
* 더 구체적인 선택자에 의해 쉽게 덮어씌워집니다.

---

## 3. 💻 실전 활용 예시

### ✅ 3.1 CSS Reset

브라우저 기본 스타일 초기화에 가장 많이 사용됩니다.

```css
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}
```

➡ 모든 요소의 여백 제거 + `box-sizing` 변경.

---

### ✅ 3.2 특정 컨테이너 내부 스타일 통일

```css
.container * {
  font-family: 'Roboto', sans-serif;
}
```

➡ `.container` 내부의 모든 요소에 동일한 폰트 적용.

---

### ✅ 3.3 형제 요소 간 간격 주기

```css
* + * {
  margin-top: 1rem;
}
```

➡ 바로 앞에 요소가 있을 때만 위 여백 추가 (레이아웃 간격 통일에 유용).

---

## 4. ⚠️ 성능 고려 사항

Universal Selector는 **DOM 전체를 탐색**해야 하기 때문에, 대규모 페이지에서는 성능에 부담이 될 수 있습니다. 🐢
그래서 다음과 같은 규칙을 지키는 것이 좋습니다.

* **CSS Reset** 같은 초기화 작업 외에는 가급적 사용 최소화
* 가능하면 **범위를 제한**해서 사용 (`.wrapper *`)
* 반복적이고 불필요한 전역 스타일 지정 피하기

---

## 5. 🎯 결론

Universal Selector는 **짧고 강력하며 직관적인 CSS 도구**입니다.
하지만 "모든 요소"를 대상으로 하는 만큼, **성능과 유지보수성을 고려하여 신중하게 사용**해야 합니다.

**👍 추천 사용 사례**

* CSS Reset
* 특정 컨테이너 내 전역 스타일
* 간격 통일
