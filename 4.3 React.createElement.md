
## ✅ 1. 정의: `React.createElement`

> `React.createElement`는 **React Element**라는 **JS 객체**를 생성하는 함수입니다.
> 브라우저의 DOM 요소가 아니라, **React가 내부적으로 사용하는 가상 노드(Virtual DOM)** 객체입니다.

---

## 🔧 2. 함수 시그니처

```ts
React.createElement(
  type,           // string 또는 React 컴포넌트
  props,          // 속성 객체 (nullable)
  ...children     // 자식 요소들
)
```

---

## ✅ 3. 주요 아규먼트트 설명

| 파라미터터          | 설명                                                        |
| ------------- | --------------------------------------------------------- |
| `type`        | `'div'`, `'span'` 같은 HTML 태그 문자열이거나, 사용자 정의 컴포넌트          |
| `props`       | `className`, `style`, `onClick`, `id` 등의 속성들 (`null`도 가능) |
| `...children` | 텍스트, JSX 요소, 배열 등 다양한 자식 요소들                              |

---

## ✅ 4. 예시: JSX vs createElement

### ✅ JSX 사용

```jsx
const element = <h1 className="title">Hello React</h1>;
```

⬇️ Babel이 자동 변환

```js
const element = React.createElement(
  'h1',
  { className: 'title' },
  'Hello React'
);
```

---

## ✅ 5. 반환값

```js
{
  type: 'h1',
  props: {
    className: 'title',
    children: 'Hello React'
  },
  key: null,
  ref: null,
  ...
}
```

> 즉, React Element는 실제 DOM이 아니라, **"DOM을 어떻게 만들지 설명하는 자바스크립트 객체"** 입니다.

---

## ✅ 6. 실제 렌더링 과정

```jsx
ReactDOM.createRoot(document.getElementById('root')).render(
  React.createElement('h1', null, 'Hello React')
);
```

1. `React.createElement(...)` → React Element (JS 객체)를 만듦
2. `ReactDOM.render(...)` 또는 `createRoot().render(...)` → 해당 Element를 진짜 DOM으로 바꿈

---

## ✅ 7. 사용자 정의 컴포넌트에도 사용 가능

```jsx
function MyButton(props) {
  return <button>{props.label}</button>;
}

const el = React.createElement(MyButton, { label: 'Click Me' });
// <MyButton label="Click Me" />
```

---

## ✅ 8. 왜 필요할까?

| 이유             | 설명                                                  |
| -------------- | --------------------------------------------------- |
| JSX는 문법 설탕     | JSX는 실제로 `React.createElement()`로 바뀜                |
| Virtual DOM 구현 | 리얼 DOM 대신 React Element를 사용하여 **비교(diffing)** 후 렌더링 |
| 컴포넌트 트리 생성     | 모든 React 컴포넌트는 내부적으로 이 함수를 통해 요소 트리를 만듦             |

---

## ✅ 9. 예제: JSX 없이 React 코딩

```js
const App = () =>
  React.createElement(
    'main',
    { style: { padding: '20px' } },
    React.createElement(
      'button',
      { onClick: () => alert('clicked') },
      '클릭'
    )
  );

const root = ReactDOM.createRoot(document.getElementById('root'));
root.render(React.createElement(App));
```

> 이처럼 JSX 없이도 React 앱은 `React.createElement()`로 구성 가능합니다 (불편하긴 하지만 😅).

---

## ✅ 정리

| 항목       | 내용                                                        |
| -------- | --------------------------------------------------------- |
| 이름       | `React.createElement`                                     |
| 역할       | JSX → JS로 변환된 함수 호출, React Element 객체 생성                  |
| 반환       | Virtual DOM 구조를 설명하는 JS 객체                                |
| 사용 위치    | JSX가 사용된 곳은 모두 자동 변환됨                                     |
| 브라우저 렌더링 | `ReactDOM.render()` 또는 `createRoot().render()`로 진짜 DOM 생성 |
