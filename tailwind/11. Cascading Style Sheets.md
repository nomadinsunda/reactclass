# 🌊 캐스케이딩 스타일 시트(CSS) 완벽 가이드

CSS는 **웹 페이지의 디자인과 레이아웃을 정의**하는 스타일 언어입니다.
"캐스케이딩(Cascading)"이라는 단어가 붙은 이유는, 스타일이 **여러 규칙과 우선순위에 따라 흐르면서 적용**되기 때문입니다.

---

## 1. 📖 CSS란?

* **C**ascading **S**tyle **S**heets
* HTML과 함께 사용되어 \*\*콘텐츠(HTML)\*\*와 \*\*표현(디자인)\*\*을 분리
* 글꼴, 색상, 크기, 배경, 레이아웃 등을 지정
* "캐스케이딩"은 여러 스타일 규칙이 겹칠 때 **우선순위에 따라 최종 스타일이 결정**되는 과정을 의미

---

## 2. 🧩 CSS 적용 방식 (3가지)

### ① 인라인 스타일 (Inline Style)

HTML 요소의 `style` 속성에 직접 작성

```html
<p style="color: red;">빨간 글씨</p>
```

### ② 내부 스타일 (Internal Style)

HTML `<head>` 안의 `<style>` 태그에 작성

```html
<style>
  p { color: blue; }
</style>
```

### ③ 외부 스타일 (External Style)

별도의 `.css` 파일로 작성 후 `<link>`로 연결

```html
<link rel="stylesheet" href="styles.css">
```

---

## 3. ⚖️ 캐스케이딩(Cascading) 원리

CSS에서 **같은 요소**에 여러 스타일 규칙이 적용될 경우, 다음 순서대로 최종 스타일이 결정됩니다.

### 3.1. 우선순위(Specificity)

1. 인라인 스타일 → 가장 강력 (`style=""`)
2. ID 선택자(`#id`)
3. 클래스 선택자(`.class`), 속성 선택자(`[type="text"]`), 가상 클래스(`:hover`)
4. 태그(타입) 선택자(`p`, `div`), 가상 요소(`::before`)
5. 전체 선택자(`*`) → 가장 낮음

### 3.2. 선언 순서(Order)

* **같은 우선순위**일 경우, **나중에 작성된 스타일**이 적용됨

### 3.3. `!important`

* 어떤 스타일에 `!important`를 붙이면, 우선순위를 무시하고 **최우선 적용**

```css
p {
  color: red !important;
}
```

⚠️ 남용 시 유지보수 어려움

---

## 4. 🎨 CSS의 역할

* **콘텐츠 스타일링:** 색상, 글꼴, 크기
* **레이아웃 구성:** Flexbox, Grid
* **반응형 웹 디자인:** 미디어 쿼리(`@media`)
* **애니메이션 & 인터랙션:** `transition`, `animation`
* **접근성 개선:** 시각적 구분, 포커스 스타일 등

---

## 5. 🧪 간단 실습

### HTML

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>CSS 예제</title>
  <link rel="stylesheet" href="style.css">
  <style>
    /* 내부 스타일 */
    h1 { color: blue; }
  </style>
</head>
<body>
  <h1 style="color: red;">캐스케이딩 스타일 시트</h1>
  <p>이 문장은 파란색입니다.</p>
</body>
</html>
```

### style.css

```css
p {
  color: blue;
}
```

➡ `h1`은 인라인 스타일(`red`)이 내부 스타일(`blue`)보다 우선 적용됨

---

## 6. 📌 정리

| 특징            | 설명                                  |
| ------------- | ----------------------------------- |
| **Cascading** | 여러 스타일 규칙이 적용될 때 우선순위와 순서에 따라 최종 결정 |
| **재사용성**      | 외부 스타일로 여러 페이지 공유 가능                |
| **유지보수성**     | HTML과 CSS 분리로 코드 관리 용이              |
| **표현력**       | 글꼴, 색상, 레이아웃, 애니메이션 등 다양한 시각 효과 제공  |

---

💬 **결론:**
CSS는 단순한 "디자인 도구"가 아니라, **웹 UI/UX를 완성하는 핵심 언어**입니다.
"캐스케이딩" 원리를 이해하면, **스타일 충돌**을 예측하고 해결할 수 있으며,
유지보수와 확장성 있는 스타일 설계가 가능합니다. 🚀
