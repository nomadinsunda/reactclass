# 🔠 CSS `font-size` 속성 완벽 가이드

웹 디자인에서 **글자 크기**는 가독성과 디자인 분위기를 좌우하는 핵심 요소입니다.
CSS의 `font-size` 속성은 HTML 요소의 **텍스트 크기**를 지정합니다.

---

## 1. 📖 `font-size`란?

* HTML 요소에 적용되는 **글꼴 크기**를 지정하는 속성
* 절대값, 상대값, 백분율, 키워드 등 다양한 단위 지원
* 문법:

  ```css
  font-size: 값;
  ```

---

## 2. 📏 단위 종류

### 2.1 절대 길이 단위

* `px`(픽셀)

  ```css
  p { font-size: 16px; }
  ```

  ➡ 화면 해상도에 따라 동일한 픽셀 크기

### 2.2 상대 길이 단위

* `em` → **부모 요소 또는 현재 요소의 font-size** 기준

  ```css
  p { font-size: 1.2em; } /* 부모의 글자 크기 × 1.2 */
  ```
* `rem` → **루트 요소(html)의 font-size** 기준

  ```css
  p { font-size: 1.5rem; } /* html의 크기 × 1.5 */
  ```
* `%` → 부모 요소의 font-size에 대한 비율

  ```css
  p { font-size: 120%; }
  ```

### 2.3 키워드

* `xx-small`, `x-small`, `small`, `medium`(기본), `large`, `x-large`, `xx-large`
* `smaller`, `larger` → 부모 크기 대비 상대적으로 작게/크게

---

## 3. 🎯 사용 예시

```css
html {
  font-size: 16px; /* 기준 */
}

h1 {
  font-size: 2rem; /* 32px */
}

p {
  font-size: 1rem; /* 16px */
}

small {
  font-size: 0.8em; /* 부모 크기 × 0.8 */
}
```

---

## 4. 📊 절대 vs 상대 단위 비교

| 단위    | 기준          | 장점          | 단점               |
| ----- | ----------- | ----------- | ---------------- |
| `px`  | 화면 픽셀       | 예측 가능       | 반응형 디자인 어려움      |
| `em`  | 부모 요소 크기    | 유연한 크기 조절   | 중첩 시 예측 어려움      |
| `rem` | 루트(html) 크기 | 일관성, 반응형 용이 | 루트 크기 변경 시 전체 영향 |
| `%`   | 부모 요소 크기    | 간단한 비율 적용   | 예측 어려움           |
| 키워드   | 브라우저 기본값    | 접근성↑        | 세밀한 제어 어려움       |

---

## 5. 🧪 실습 예제

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>font-size 예제</title>
  <style>
    html { font-size: 16px; }
    h1 { font-size: 2rem; }
    p { font-size: 1rem; }
    .small-text { font-size: 0.8em; }
    .big-text { font-size: 150%; }
  </style>
</head>
<body>
  <h1>font-size 데모</h1>
  <p>이 문장은 기본 크기(16px)입니다.</p>
  <p class="small-text">이 문장은 조금 작아요.</p>
  <p class="big-text">이 문장은 더 커요!</p>
</body>
</html>
```

---

## 6. 💡 접근성과 반응형 고려

* 기본적으로 **`html { font-size: 100%; }`** (브라우저 기본값 약 16px)을 권장
* 반응형 디자인에서는 `rem`과 미디어 쿼리(@media) 조합 활용
* 시각 장애 사용자 접근성을 위해 너무 작은 크기는 피하기

---

💬 **결론:**
`font-size`는 단순한 크기 지정이 아니라, **반응형·접근성·디자인 일관성**을 모두 고려해야 하는 속성입니다.
특히 **`rem` 기반 설계**는 유지보수성과 반응형 대응에 강력한 방법입니다. 🚀
