# 🌱 CSS 스타일 상속(Inheritance) 완벽 가이드

CSS에는 **부모 요소의 스타일이 자식 요소에게 자동으로 전달**되는 특성이 있습니다.
이를 \*\*스타일 상속(Inheritance)\*\*이라고 합니다.
HTML 구조를 효율적으로 스타일링하는 핵심 개념이죠.

---

## 1. 📖 스타일 상속이란?

* 부모 요소에 적용된 **일부 CSS 속성**이 자식 요소에게 **자동 적용**되는 것
* HTML 문서는 \*\*트리 구조(DOM)\*\*로 되어 있기 때문에 상속 개념이 가능
* 모든 속성이 상속되는 것은 아님 → **상속되는 속성과 상속되지 않는 속성**이 있음

---

## 2. 📝 예시

```html
<div style="color: red;">
  <p>이 문장은 빨간색입니다.</p>
  <span>이 문장도 빨간색입니다.</span>
</div>
```

* 부모 `<div>`에 `color: red`를 지정했지만,
* 자식 `<p>`와 `<span>`에도 자동으로 글자 색이 적용됨

---

## 3. 🔍 상속되는 대표 속성

### ✅ 상속 O (주로 **텍스트 관련 속성**)

* `color`
* `font`, `font-family`, `font-size`, `font-weight`, `font-style`
* `line-height`
* `visibility`
* `cursor`
* `text-align`, `text-indent`, `text-transform`

### ❌ 상속 X (주로 **박스 모델 및 레이아웃 속성**)

* `margin`, `padding`
* `border`, `background`
* `width`, `height`
* `display`, `position`
* `flex`, `grid` 관련 속성

---

## 4. 🎛 상속 제어

### 4.1 `inherit`

* 부모 요소의 값을 강제로 상속받게 함

```css
p {
  border: inherit; /* 원래는 상속 안 되지만 강제로 상속 */
}
```

### 4.2 `initial`

* 속성을 기본값으로 초기화

```css
p {
  color: initial; /* 브라우저 기본 색상으로 되돌림 */
}
```

### 4.3 `unset`

* 해당 속성을 **상속 가능 속성은 inherit**, **상속 불가 속성은 initial**로 적용

```css
p {
  color: unset;
}
```

---

## 5. 🧪 실습 예제

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>CSS 상속 예제</title>
  <style>
    body {
      font-family: Arial, sans-serif;
      color: darkblue;
    }
    p {
      border: 1px solid gray; /* border는 상속 안 됨 */
    }
  </style>
</head>
<body>
  <h1>상속 예제</h1>
  <p>이 문장은 darkblue 색상을 상속받습니다.</p>
  <div>
    <span>이 텍스트도 상속받아 darkblue입니다.</span>
  </div>
</body>
</html>
```

---

## 6. 📌 정리

| 구분         | 설명                            | 예시                   |
| ---------- | ----------------------------- | -------------------- |
| 상속되는 속성    | 주로 텍스트 관련 속성                  | `color`, `font-size` |
| 상속 안 되는 속성 | 박스 모델, 레이아웃 속성                | `margin`, `border`   |
| 제어 키워드     | `inherit`, `initial`, `unset` | 상속 여부 제어 가능          |

---

💬 **결론:**
스타일 상속을 이해하면 **코드 중복을 줄이고 유지보수성을 높일 수 있습니다**.
특히 텍스트 스타일은 상속을 활용하면 효율적으로 관리할 수 있고,
상속되지 않는 속성은 필요할 때 `inherit`를 사용해 강제로 적용할 수 있습니다. 🚀
