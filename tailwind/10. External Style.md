# 🌍 CSS 외부 스타일(External Style) 완벽 가이드

웹 페이지에서 CSS를 적용하는 가장 **전문적이고 확장성 높은 방식**이 바로 \*\*외부 스타일(External Style)\*\*입니다.
별도의 `.css` 파일을 만들어 HTML 문서와 연결하는 방법으로, 실무 프로젝트에서 가장 일반적으로 사용됩니다.

---

## 1. 📖 외부 스타일이란?

* CSS 코드를 **HTML 문서와 분리**하여 `.css` 파일로 저장
* HTML 문서의 `<head>`에 `<link>` 태그를 이용해 연결
* 한 개의 CSS 파일을 **여러 HTML 문서에서 재사용** 가능
* 문법:

  ```html
  <link rel="stylesheet" href="경로/파일명.css">
  ```

---

## 2. 📝 예시

### style.css

```css
body {
  font-family: Arial, sans-serif;
  background-color: #f3f4f6;
}

h1 {
  color: #4f46e5;
  text-align: center;
}
```

### index.html

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>외부 스타일 예제</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>외부 스타일 적용</h1>
  <p>이 페이지는 외부 CSS 파일을 사용합니다.</p>
</body>
</html>
```

---

## 3. 🔍 특징

### ✅ 장점

1. **재사용성 높음** → 한 CSS 파일을 여러 페이지에서 사용 가능
2. **유지보수 용이** → 스타일 변경 시 연결된 모든 페이지에 반영
3. **HTML과 CSS의 분리** → 코드 구조가 깔끔해짐

### ⚠️ 단점

1. **네트워크 요청 필요** → CSS 파일이 로드되기 전에는 스타일 적용이 안 될 수 있음
2. **소규모 단일 페이지**에는 오히려 번거로울 수 있음

---

## 4. 📊 우선순위(Specificity)

* 외부 스타일은 내부 스타일과 동일한 우선순위를 가짐 (`0,0,1,0` 등 선택자에 따라 결정)
* **나중에 로드된 CSS**가 같은 요소를 덮어쓸 수 있음
* 인라인 스타일보다 우선순위 낮음

---

## 5. 💡 사용 사례

* 대규모 웹사이트, 웹 애플리케이션
* 여러 페이지가 공통 스타일을 공유하는 프로젝트
* 유지보수가 중요한 프로젝트

---

## 6. 🧪 실습 예제

📂 **폴더 구조**

```
project/
│ index.html
│ about.html
│ style.css
```

### style.css

```css
header {
  background-color: #4f46e5;
  color: white;
  padding: 20px;
}

main {
  padding: 20px;
}
```

### index.html

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>홈페이지</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <header>홈페이지 헤더</header>
  <main>메인 콘텐츠</main>
</body>
</html>
```

### about.html

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>소개 페이지</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <header>소개 페이지 헤더</header>
  <main>소개 내용</main>
</body>
</html>
```

➡ **하나의 style.css**를 두 HTML 페이지에서 공유

---

## 7. 📌 정리

| 방식         | 적용 위치          | 재사용성 | 우선순위  | 유지보수 |
| ---------- | -------------- | ---- | ----- | ---- |
| 인라인 스타일    | 요소 `style` 속성  | 낮음   | 매우 높음 | 어려움  |
| 내부 스타일     | HTML `<style>` | 중간   | 보통    | 보통   |
| **외부 스타일** | 별도 `.css` 파일   | 높음   | 보통    | 쉬움   |

---

💬 **결론:**
외부 스타일은 **대규모 프로젝트와 다중 페이지 사이트**에 최적화된 방식입니다.
**HTML과 CSS를 분리**해 유지보수성과 확장성을 확보할 수 있기 때문에, 실무에서는 거의 필수적으로 사용됩니다.
