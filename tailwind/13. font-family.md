# ✍️ CSS `font-family` 속성 완벽 가이드

웹 디자인에서 글꼴은 **브랜드 이미지와 가독성**을 결정하는 중요한 요소입니다.
CSS의 `font-family` 속성은 HTML 요소에 적용할 **글꼴(폰트) 계열**을 지정하는 역할을 합니다.

---

## 1. 📖 `font-family`란?

* HTML 요소에 적용할 글꼴을 **우선순위 목록**으로 지정
* 브라우저는 목록의 **첫 번째 사용 가능한 폰트**를 적용
* 나열된 폰트를 사용할 수 없으면 **대체 폰트(fallback)** 사용
* 문법:

  ```css
  font-family: "첫 번째 폰트", "두 번째 폰트", generic-family;
  ```

---

## 2. 📝 기본 예시

```css
body {
  font-family: "Helvetica Neue", Arial, sans-serif;
}
```

* **1순위:** Helvetica Neue
* **2순위:** Arial
* **마지막:** 브라우저 기본 sans-serif 폰트

---

## 3. 🎯 Generic Font Family (글꼴 계열)

`font-family`의 마지막에는 반드시 **generic-family**를 지정하는 것이 권장됩니다.
이 값은 글꼴 계열을 의미하며, 브라우저가 해당 계열에서 가능한 폰트를 자동 선택합니다.

| Generic Family | 설명                      | 예시 폰트                    |
| -------------- | ----------------------- | ------------------------ |
| `serif`        | 글자 끝에 장식(획)이 있는 전통적인 서체 | Times New Roman, Georgia |
| `sans-serif`   | 장식 없는 깔끔한 서체            | Arial, Helvetica         |
| `monospace`    | 모든 글자가 같은 너비            | Courier New, Consolas    |
| `cursive`      | 손글씨 스타일                 | Brush Script MT          |
| `fantasy`      | 장식적인 폰트                 | Papyrus                  |

---

## 4. 💡 큰따옴표 사용 규칙

* **공백이 있는 글꼴 이름**은 큰따옴표(`"`) 또는 작은따옴표(`'`)로 감싸야 함

  ```css
  font-family: "Open Sans", sans-serif;
  ```
* 단어 하나짜리 폰트 이름은 따옴표 없이 가능

  ```css
  font-family: Arial, sans-serif;
  ```

---

## 5. 🧪 실습 예제

HTML:

```html
<p class="serif">이 문장은 serif 계열 폰트를 사용합니다.</p>
<p class="sans">이 문장은 sans-serif 계열 폰트를 사용합니다.</p>
<p class="mono">이 문장은 monospace 계열 폰트를 사용합니다.</p>
```

CSS:

```css
.serif {
  font-family: Georgia, "Times New Roman", serif;
}
.sans {
  font-family: Arial, Helvetica, sans-serif;
}
.mono {
  font-family: "Courier New", Courier, monospace;
}
```

---

## 6. ⚠️ 주의 사항

* **웹 폰트 사용 시**는 `@font-face` 또는 Google Fonts 같은 CDN 활용
* 사용자 OS에 설치되지 않은 로컬 폰트는 적용되지 않음
* 항상 \*\*대체 폰트(fallback)\*\*를 지정해 예기치 않은 폰트 깨짐 방지

---

💬 **결론:**
`font-family`는 단순히 예쁜 글꼴을 지정하는 것이 아니라, **사용자 환경에 맞는 대체 시스템**을 설계하는 속성입니다.
항상 폰트 우선순위와 generic-family를 함께 지정하는 습관이 중요합니다. 🚀

---


## 1) 기본: 커스텀 폰트 불러오기 + 폴백 설정 🌐

```css
/* 1. 폰트 선언 */
@font-face {
  font-family: "PretendardCustom";
  src:
    local("Pretendard"),
    url("/fonts/pretendard-regular.woff2") format("woff2");
  font-weight: 400;
  font-style: normal;
  font-display: swap; /* ⏱️ 로딩 중 시스템 폰트 먼저 표시 */
}

/* 2. 사용 시 폴백 스택 구성 */
body {
  font-family: "PretendardCustom", -apple-system, BlinkMacSystemFont,
               "Segoe UI", Roboto, "Noto Sans KR", Arial, sans-serif;
}
```

**포인트**

* `local()` → 사용자의 로컬에 폰트가 있으면 네트워크 요청 생략
* `font-display: swap` → FOUT 전략(로딩 중에도 텍스트 보이게)

---

## 2) 굵기/스타일 여러 개 등록하기 🧱

```css
@font-face {
  font-family: "PretendardCustom";
  src: url("/fonts/pretendard-regular.woff2") format("woff2");
  font-weight: 400; /* Regular */
  font-style: normal;
  font-display: swap;
}

@font-face {
  font-family: "PretendardCustom";
  src: url("/fonts/pretendard-bold.woff2") format("woff2");
  font-weight: 700; /* Bold */
  font-style: normal;
  font-display: swap;
}

h1 { font-weight: 700; } /* 같은 family에 굵기만 변경 */
```

---

## 3) 가변 폰트(Variable Font) 한 방에 등록하기 ⚖️

```css
@font-face {
  font-family: "InterVar";
  src: url("/fonts/Inter-roman.var.woff2") format("woff2-variations");
  font-weight: 100 900;   /* 가변 축 범위 */
  font-stretch: 75% 125%;
  font-style: normal;
  font-display: swap;
}

h1 { font-family: "InterVar", system-ui, sans-serif; font-weight: 700; }
p  { font-family: "InterVar", system-ui, sans-serif; font-weight: 450; }
```

**장점:** 굵기 파일 여러 개 대신 **하나로** 커버 → 요청 수 감소, 디자인 유연성 ↑

---

## 4) 유니코드 서브셋(선택)로 용량 최적화 ✂️

```css
@font-face {
  font-family: "NotoSansKR-Subset";
  src: url("/fonts/NotoSansKR-subset.woff2") format("woff2");
  font-weight: 400;
  unicode-range: U+AC00-D7A3, U+0020-007E; /* 한글, 기본 라틴 */
  font-display: swap;
}
```

특정 문자 범위만 포함한 파일을 제공해 **다운로드 용량**을 줄입니다.

---

## 5) Google Fonts로 간단하게 불러오기 🚀

```html
<!-- 성능 최적화: 사전연결 -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>

<!-- display=swap 권장 -->
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;700&display=swap"
      rel="stylesheet">
```

```css
body { font-family: "Inter", -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif; }
```

## 6) 체크리스트 ✅

* [ ] **형식**: 가능하면 `woff2` 사용 (용량/호환성 베스트)
* [ ] **표시 전략**: `font-display: swap`으로 로딩 중 텍스트 숨김 방지
* [ ] **폴백 스택**: `system-ui`/플랫폼 폰트 포함해 자연스러운 대체
* [ ] **가변 폰트**: 굵기 다양하면 Variable Font 고려
* [ ] **서브셋**: 필요한 문자만 제공해 크기 절감
* [ ] **접근성**: 라이트/다크 모드 대비와 가독성(라인하이트, 대비) 함께 조정
* [ ] **권한**: 상용 폰트 라이선스 확인 필수
