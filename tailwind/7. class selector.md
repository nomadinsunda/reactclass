
# 🎯 CSS Class Selector 완벽 가이드 (강의 자료)

CSS에서 가장 많이 사용되는 선택자가 무엇인지 아시나요?
바로 \*\*Class Selector(`.class`)\*\*입니다.
재사용성과 유지보수성 덕분에, 실무에서도 클래스 선택자가 표준처럼 쓰입니다.

---

## 1. 📖 Class Selector란?

**Class Selector**는 HTML 요소의 `class` 속성을 이용해 스타일을 적용하는 CSS 선택자입니다.
하나의 클래스는 여러 요소에서 **공유 가능**하며, 요소 하나가 여러 개의 클래스를 가질 수도 있습니다.

---

## 2. 📝 문법

```css
.클래스명 {
  /* 스타일 */
}
```

예시:

```css
.button {
  padding: 10px 20px;
  border-radius: 8px;
}
```

---

## 3. HTML에서 사용 방법

```html
<button class="button">확인</button>
<p class="highlight">이 부분은 강조됩니다.</p>
```

* `class="button"` → `.button`으로 CSS에서 선택
* 클래스 이름은 **공백 없이**, 숫자로 시작하지 않도록 작성 권장
  (`btn-primary` ✅, `123btn` ❌)

---

## 4. CSS 적용 예시

HTML:

```html
<div class="card">카드 1</div>
<div class="card">카드 2</div>
<div class="card">카드 3</div>
```

CSS:

```css
.card {
  background: #f9fafb;
  border: 1px solid #d1d5db;
  padding: 16px;
  border-radius: 8px;
}
```

➡ 같은 `.card` 클래스를 가진 모든 요소에 동일 스타일 적용.

---

## 5. 🔍 특징

1. **Specificity(우선순위)**: `0,0,1,0` → Type Selector(`p`)보다 높고, ID Selector(`#id`)보다 낮음.
2. **재사용 가능** → 동일한 디자인을 여러 요소에 쉽게 적용.
3. 한 요소가 **여러 클래스**를 가질 수 있음 (`class="btn btn-primary"`).
4. HTML 구조 변경에 비교적 강함 → 유지보수 용이.

---

## 6. 💡 활용 사례

### (1) 버튼 스타일 재사용

```css
.btn {
  padding: 0.75rem 1.5rem;
  border-radius: 6px;
}
.btn-primary {
  background-color: #2563eb;
  color: white;
}
.btn-secondary {
  background-color: #e5e7eb;
  color: #111827;
}
```

HTML:

```html
<button class="btn btn-primary">저장</button>
<button class="btn btn-secondary">취소</button>
```

---

### (2) 상태/조건 스타일 지정

```css
.active {
  font-weight: bold;
}
.hidden {
  display: none;
}
```

HTML:

```html
<p class="active">현재 선택됨</p>
<p class="hidden">이 문장은 숨김</p>
```

---

### (3) 특정 컨테이너 내부 제한

```css
.article .highlight {
  background-color: yellow;
}
```

HTML:

```html
<div class="article">
  <p class="highlight">이 문장은 노란색 배경</p>
</div>
```

---

## 7. 🧪 실습 예제

HTML:

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>Class Selector Example</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1 class="title">Class Selector 실습</h1>
  <p class="highlight">이 부분은 강조됩니다.</p>
  <button class="btn btn-primary">확인</button>
  <button class="btn btn-secondary">취소</button>
</body>
</html>
```

CSS (style.css):

```css
.title {
  text-align: center;
  color: darkgreen;
}

.highlight {
  background-color: yellow;
}

.btn {
  padding: 0.75rem 1.5rem;
  border-radius: 6px;
}

.btn-primary {
  background-color: #2563eb;
  color: white;
}

.btn-secondary {
  background-color: #e5e7eb;
  color: #111827;
}
```

---

## 8. ⚠️ 주의점

* 클래스명은 HTML 문서 내에서 **중복 가능**하나, 너무 광범위하게 쓰면 스타일 충돌 가능.
* **네이밍 규칙**(BEM, SMACSS 등)을 사용하면 유지보수성 ↑.
* **역할 중심 네이밍** 권장 (예: `.btn-primary`), 형태 중심 네이밍(예: `.red-text`)은 피하기.

---

## 9. 📌 정리

| 선택자       | 문법       | Specificity | 재사용성 | 우선 사용 사례  |
| --------- | -------- | ----------- | ---- | --------- |
| Universal | `*`      | 0,0,0,0     | 낮음   | CSS Reset |
| Type      | `p`      | 0,0,0,1     | 낮음   | 기본 태그 스타일 |
| Class     | `.class` | 0,0,1,0     | 높음   | 반복 UI 패턴  |
| ID        | `#id`    | 0,1,0,0     | 낮음   | 유일한 요소    |
