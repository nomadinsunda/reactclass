

# 🎨 CSS 인라인 스타일(Inline Style) 완벽 가이드

HTML 요소에 스타일을 적용하는 방법은 여러 가지가 있습니다.
그중 가장 **직접적이고 빠른 방법**이 바로 **인라인 스타일(Inline Style)** 입니다.

---

## 1. 📖 인라인 스타일이란?

* HTML 요소의 **`style` 속성** 안에 CSS 속성과 값을 직접 작성하는 방식.
* 외부 CSS 파일이나 `<style>` 태그 없이, **해당 요소에만 즉시 적용**.
* 문법:

  ```html
  <태그 style="속성: 값; 속성: 값;">
  ```

---

## 2. 📝 예시

```html
<p style="color: red; font-size: 20px;">
  이 문장은 빨간색이고, 글자 크기는 20px입니다.
</p>
```

* `color: red;` → 글자 색상 빨강
* `font-size: 20px;` → 글자 크기 20px

---

## 3. 🔍 특징

### ✅ 장점

1. **즉시 적용** → 별도 CSS 파일 없이 바로 스타일 지정
2. **요소 단위 제어** 가능
3. **JavaScript에서 쉽게 변경 가능**

   ```js
   document.getElementById("myDiv").style.backgroundColor = "yellow";
   ```

### ⚠️ 단점

1. **재사용 불가** → 다른 요소에 동일 스타일 적용하려면 반복 작성
2. **유지보수 어려움** → HTML과 CSS가 섞여 코드 가독성 ↓
3. **우선순위 매우 높음** → 나중에 스타일 변경 시 예상치 못한 덮어쓰기 문제 발생

---

## 4. 📊 우선순위(Specificity)

CSS 우선순위에서 인라인 스타일은 **가장 강력한 수준**입니다.

* Specificity: `1,0,0,0`
* 심지어 ID Selector보다도 우선 적용됩니다.
* 단, `!important`를 사용하면 인라인 스타일도 덮어쓸 수 있습니다.

---

## 5. 💡 사용 사례

* 이메일 HTML 템플릿 (외부 CSS 제한이 있는 경우)
* 빠른 테스트/디버깅
* JS로 동적 스타일 변경
* 아주 국소적인 스타일 변경

---

## 6. 🧪 실습 예제

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>인라인 스타일 예제</title>
</head>
<body>
  <h1 style="color: blue; text-align: center;">인라인 스타일</h1>
  <p style="background-color: lightyellow; padding: 10px;">
    이 문장은 인라인 스타일로 배경색과 패딩이 적용되었습니다.
  </p>
</body>
</html>
```

---

## 7. 📌 정리

| 방식                | 적용 위치          | 재사용성 | 우선순위  | 유지보수 |
| ----------------- | -------------- | ---- | ----- | ---- |
| 인라인 스타일           | 요소의 `style` 속성 | 낮음   | 매우 높음 | 어려움  |
| 내부 CSS(`<style>`) | HTML head      | 중간   | 중간    | 보통   |
| 외부 CSS 파일         | 별도 .css 파일     | 높음   | 중간    | 쉬움   |

---

💬 **결론:**
인라인 스타일은 **즉시 적용**과 **간단성**이 장점이지만, **재사용성과 유지보수성**이 떨어집니다.
실무에서는 **빠른 테스트나 특수한 상황**에서만 사용하고,
대부분은 **클래스/ID + 외부 CSS 파일**로 관리하는 것을 권장합니다.
