

# 🏷 CSS Type Selector 완벽 가이드

CSS에서 특정 **HTML 태그 이름**을 기준으로 스타일을 적용하고 싶을 때 사용하는 것이 **Type Selector**입니다.
예를 들어 `p` 태그만, `h1` 태그만, `button` 태그만 스타일링하고 싶을 때 딱 맞죠.

---

## 1. 📖 Type Selector란?

**Type Selector**는 **HTML 요소의 태그 이름**을 직접 선택하는 선택자입니다.
문법은 단순히 태그명을 쓰면 됩니다.

```css
태그명 {
  /* 스타일 */
}
```

예시 📝:

```css
p {
  color: #333;
}
```

➡ HTML의 모든 `<p>` 요소에 `color: #333`이 적용됩니다.

---

## 2. 🧐 특징

### 🔹 2.1 태그 기반 선택

* `div`, `h1`, `button`, `span` 등 **HTML의 기본 요소명**이 선택 기준입니다.

### 🔹 2.2 Specificity(우선순위)

* **Specificity 값:** `0,0,0,1`
* Universal Selector(`*`)보다 **우선순위가 높음**.
* 하지만 클래스나 아이디 선택자보다 낮음.

### 🔹 2.3 HTML 문서 전체에 적용

* 같은 태그명이면 문서 어디에 있든 전부 적용됩니다.
* 범위를 제한하려면 **조합 선택자**와 함께 사용합니다.

---

## 3. 💻 실전 활용 예시

### ✅ 3.1 기본 스타일링

```css
h1 {
  font-size: 2rem;
  font-weight: bold;
}
```

➡ 모든 `<h1>` 태그를 굵고 크게 표시.

---

### ✅ 3.2 특정 영역 제한

```css
.article-content p {
  line-height: 1.6;
}
```

➡ `.article-content` 클래스 내부에 있는 `<p>` 태그만 선택.

---

### ✅ 3.3 여러 타입 동시 선택

```css
h1, h2, h3 {
  font-family: 'Roboto', sans-serif;
}
```

➡ `h1`, `h2`, `h3` 제목 태그를 한 번에 스타일링.

---

## 4. ⚖️ Universal Selector와 비교

| 구분          | Universal Selector (`*`) | Type Selector (`p`, `div`, etc.) |
| ----------- | ------------------------ | -------------------------------- |
| 선택 대상       | 모든 요소                    | 특정 태그명                           |
| Specificity | `0,0,0,0` (가장 낮음)        | `0,0,0,1`                        |
| 성능          | DOM 전체 탐색                | 해당 태그만 탐색                        |
| 사용 사례       | CSS Reset, 전역 규칙         | 특정 요소 스타일 지정                     |

💡 **결론:** 범위를 좁히고 싶은 경우에는 Type Selector를 쓰는 것이 성능적으로나 유지보수 측면에서 더 유리합니다.

---

## 5. ⚠️ 주의 사항

* Type Selector만 쓰면 **재사용성이 떨어질 수 있음** (태그가 바뀌면 스타일 깨짐).
* 프로젝트 규모가 커질수록 **클래스 기반 스타일링**이 더 안정적.
* HTML 구조 변경에 취약하므로, **의미 있는 클래스와 함께 사용** 권장.

---

## 6. 🎯 결론

Type Selector는 HTML 태그명을 기준으로 스타일을 지정하는 간단하면서도 강력한 선택자입니다.
그러나 유지보수성과 확장성을 위해 **클래스 선택자와 병행 사용**하는 것이 좋습니다.
