# 🏠 CSS 내부 스타일(Internal Style) 완벽 가이드

웹 페이지에서 CSS를 적용하는 방법은 3가지가 있습니다.
그중 \*\*내부 스타일(Internal Style)\*\*은 HTML 문서 안의 `<style>` 태그에 CSS를 작성하는 방식입니다.
외부 CSS 파일 없이도 한 문서 안에서 깔끔하게 스타일을 관리할 수 있습니다.

---

## 1. 📖 내부 스타일이란?

* HTML 문서의 `<head>` 태그 안에 `<style>` 태그를 두고 CSS를 작성하는 방법
* 해당 HTML 문서에만 스타일이 적용됨 (다른 HTML에는 영향 없음)
* 문법:

  ```html
  <style>
    선택자 { 속성: 값; }
  </style>
  ```

---

## 2. 📝 예시

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>내부 스타일 예제</title>
  <style>
    h1 {
      color: blue;
      text-align: center;
    }
    p {
      background-color: lightyellow;
      padding: 10px;
    }
  </style>
</head>
<body>
  <h1>내부 스타일 적용</h1>
  <p>이 문장은 내부 스타일로 스타일링되었습니다.</p>
</body>
</html>
```

---

## 3. 🔍 특징

### ✅ 장점

1. **외부 파일 불필요** → CSS를 HTML 안에 포함
2. **한 문서에만 적용 가능** → 특정 페이지 전용 스타일 작성 용이
3. **HTML과 CSS를 한 파일에서 관리** → 간단한 페이지 제작에 유리

### ⚠️ 단점

1. **재사용성 낮음** → 다른 HTML에 쓰려면 복사/붙여넣기 필요
2. HTML과 CSS가 섞여 코드 길어짐 → 유지보수성 떨어질 수 있음
3. 여러 페이지 공통 스타일 관리 어려움 → 대규모 프로젝트에 비효율적

---

## 4. 📊 우선순위(Specificity)

* 내부 스타일은 외부 CSS와 동일한 우선순위를 가짐
* **나중에 작성된 규칙이 우선 적용** (CSS의 Cascade 원리)
* 인라인 스타일보다는 낮음, 외부 스타일과 충돌 시 선언 순서에 따라 결정

---

## 5. 💡 사용 사례

* 단일 HTML 페이지 스타일링 (이벤트 랜딩 페이지, 이메일용 HTML)
* 간단한 프로토타입 제작
* 외부 파일 관리가 번거로운 소규모 프로젝트

---

## 6. 🧪 실습 예제

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>Internal Style 실습</title>
  <style>
    body {
      font-family: Arial, sans-serif;
      margin: 0;
    }
    .header {
      background-color: #4f46e5;
      color: white;
      padding: 20px;
      text-align: center;
    }
    .content {
      padding: 20px;
    }
  </style>
</head>
<body>
  <div class="header">내부 스타일 예제</div>
  <div class="content">
    <p>이 페이지는 내부 스타일을 사용해 스타일링되었습니다.</p>
  </div>
</body>
</html>
```

---

## 7. 📌 정리

| 방식         | 적용 위치             | 재사용성 | 우선순위  | 유지보수 |
| ---------- | ----------------- | ---- | ----- | ---- |
| 인라인 스타일    | 요소의 `style` 속성    | 낮음   | 매우 높음 | 어려움  |
| **내부 스타일** | HTML `<style>` 태그 | 중간   | 보통    | 보통   |
| 외부 스타일     | 별도 .css 파일        | 높음   | 보통    | 쉬움   |

---

💬 **결론:**
내부 스타일은 한 페이지 전용 스타일 작성에 적합하지만, **여러 페이지에 공통 스타일을 적용해야 하는 경우**에는 외부 CSS 파일을 사용하는 것이 훨씬 효율적입니다.
