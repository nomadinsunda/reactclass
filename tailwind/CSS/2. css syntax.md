

# 🎨 CSS 기본 구문 완벽 가이드

CSS(Cascading Style Sheets)는 웹 페이지의 디자인과 레이아웃을 제어하는 스타일 언어입니다. 

---

## 1️⃣ CSS 기본 구조 🏗️

모든 CSS 코드는 다음 기본 형태를 따릅니다.

```css
선택자 {
  속성: 값;
  속성: 값;
}
```

* **🎯 선택자(Selector)** → 스타일을 적용할 HTML 요소 지정
* **⚙️ 속성(Property)** → 변경할 스타일 항목
* **🎨 값(Value)** → 속성에 설정할 구체적인 값
* **📦 선언 블록(Declaration Block)** → `{}` 안에 속성-값 쌍 모음
* **✔️ 세미콜론(;)** → 각 속성 끝에 붙여 선언 구분 (마지막에도 붙이는 습관이 안전)

**예시**

```css
p {
  color: #333;        /* 글자 색상 */
  line-height: 1.6;   /* 줄 간격 */
}
```

---

## 2️⃣ 선택자 마스터하기 🔍

### 🔹 기본 선택자

* **요소 선택자** → `p`, `div`, `h1`
* **클래스 선택자** → `.classname`
* **ID 선택자** → `#idname`

```css
.container { max-width: 1200px; }
#main { padding: 20px; }
```

### 🔹 그룹 선택자

여러 요소에 동일한 스타일 적용

```css
h1, h2, h3 { font-family: Arial, sans-serif; }
```

### 🔹 결합 선택자(Combinators)

* **하위**: `div p`
* **자식**: `div > p`
* **인접 형제**: `h1 + p`
* **일반 형제**: `h1 ~ p`

### 🔹 의사 클래스(Pseudo-class)

요소의 **상태**에 따라 스타일 적용

```css
a:hover { color: red; }
input:focus { outline: 2px solid blue; }
```

### 🔹 의사 요소(Pseudo-element)

요소의 특정 부분만 스타일 적용

```css
p::first-line { font-weight: bold; }
button::after { content: ' →'; }
```

---

## 3️⃣ 속성과 값 📏🎨

### 📏 단위(Unit)

* 절대: `px`
* 상대: `em`, `rem`, `%`
* 뷰포트 기반: `vw`, `vh`

### 🎨 색상(Color)

* HEX: `#ff0000`
* RGB: `rgb(255, 0, 0)`
* HSL: `hsl(0, 100%, 50%)`

### 🔑 특수 키워드

* `auto` → 브라우저 자동 계산
* `inherit` → 부모 값 상속
* `initial` → 브라우저 기본값
* `unset` → inherit 또는 initial

---

## 4️⃣ 캐스케이딩 & 우선순위 🏆

CSS의 **C**는 Cascading, 즉 스타일이 겹칠 때 우선순위를 적용한다는 뜻입니다.

### 📊 명시도(Specificity) 점수

1. 인라인 스타일 → 1000점
2. ID 선택자 → 100점
3. 클래스 / 속성 / 의사 클래스 → 10점
4. 요소 / 의사 요소 → 1점

### 📌 규칙

* 점수가 높은 스타일이 우선
* 점수가 같으면 **나중에 작성된 것**이 우선
* `!important` → 최상위 우선권 (⚠️ 남용 금지)

---

## 5️⃣ 주석 📝

```css
/* 주요 섹션 스타일 */
section.hero { padding: 4rem 0; }
```

* CSS 주석은 `/* */` 형식만 가능
* HTML 주석(`<!-- -->`)은 CSS에서 불가능

---

## 6️⃣ 유지보수성을 높이는 전략 📚

* **BEM 네이밍** → `.block__element--modifier`
* **CSS 변수** → 재사용성 향상

```css
:root {
  --primary-color: #007bff;
}
.btn-primary { background-color: var(--primary-color); }
```

* **OOCSS/SMACSS** → 역할 기반 파일 구조화
* **Reset / Normalize CSS** → 브라우저 기본 스타일 통일

---

## 7️⃣ 전문가 실무 팁 🚀

* 모바일 퍼스트(Media Query)로 반응형 설계 📱
* DevTools로 실시간 디버깅 🔍
* 복잡한 선택자 줄이기 → 성능 최적화 ⚡
* 접근성(ARIA 속성) 고려 ♿

---

💡 **정리**
CSS 기본 구문을 이해하는 것은 모든 프론트엔드 개발의 기초입니다. 이를 잘 숙지하면 Tailwind, Bootstrap 같은 프레임워크도 훨씬 쉽게 다룰 수 있습니다.
