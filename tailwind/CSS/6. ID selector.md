

# 🆔 CSS ID Selector

## 1. ID Selector란?

* HTML에서 **`id` 속성을 가진 요소를 선택**하는 CSS 선택자
* 문서 내에서 **유일(unique)** 해야 함
* 문법: `#` + ID 이름

---

## 2. 문법

```css
#아이디명 {
  /* 스타일 */
}
```

예시:

```css
#title {
  color: blue;
  font-size: 24px;
}
```

---

## 3. HTML에서 사용 방법

```html
<h1 id="title">안녕하세요!</h1>
```

* `id="title"` 속성을 가진 요소를 CSS에서 `#title`로 선택 가능
* **하나의 문서에서 동일한 ID를 두 번 쓰면 안 됨**

---

## 4. CSS 적용 예시

HTML:

```html
<div id="header">헤더 영역</div>
<div id="content">본문 내용</div>
```

CSS:

```css
#header {
  background-color: lightblue;
  padding: 20px;
}

#content {
  background-color: lightyellow;
  padding: 20px;
}
```

---

## 5. 특징

1. **Specificity(우선순위)**: `0,1,0,0` → 클래스(`.class`)보다 높음
2. 한 문서에서 **중복 사용 불가**
3. 브라우저가 ID로 요소를 찾는 속도가 빠름
4. **재사용성 낮음** → 반복되는 디자인에는 적합하지 않음

---

## 6. 주의점

* 너무 강한 우선순위로 인해 스타일 덮어쓰기가 어려울 수 있음
* 스타일 재사용이 힘드므로 **반복되는 스타일은 클래스**로 관리 권장
* HTML 구조 변경 시 유지보수 부담이 커질 수 있음

---

## 7. 실습 예제

### HTML

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>ID Selector Example</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1 id="main-title">CSS ID Selector 예제</h1>
  <p>이 문장은 스타일이 적용되지 않습니다.</p>
  <button id="submit-btn">제출</button>
</body>
</html>
```

### CSS (style.css)

```css
#main-title {
  color: darkgreen;
  text-align: center;
}

#submit-btn {
  background-color: orange;
  color: white;
  padding: 10px 20px;
  border: none;
  cursor: pointer;
}
```

---

💡 **TIP**

* ID Selector는 **앵커 링크**(`href="#section1"`)나 **JavaScript 조작**(e.g. `getElementById`)과 함께 많이 사용됨.
* CSS에서는 **유일한 요소**에만 스타일을 적용할 때 사용하고, 일반적인 스타일링은 클래스 선택자로 하는 것이 유지보수에 좋음.
