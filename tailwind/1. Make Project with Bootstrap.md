# Vite + React (JS) + Bootstrap: 첫 번째 예제

아래 가이드는 **Vite 기반 React(자바스크립트)** 프로젝트에 **Bootstrap 5**를 설치하고, 바로 작동하는 간단한 UI(네비게이션바, 그리드, 카드, 모달)를 만드는 첫 예제입니다.

---

## 0) 사전 조건

* Node.js 18+ 권장
* npm 또는 pnpm/yarn 중 택1

---

## 1) 프로젝트 생성

```bash
# Vite + React (JavaScript)
npm create vite@latest my-bootstrap-app -- --template react
cd my-bootstrap-app
npm install
```

---

## 2) Bootstrap 설치

```bash
npm i bootstrap@5
```

> 모달/드롭다운 등 JavaScript 동작이 필요한 컴포넌트를 쓰려면 **bundle**을 로드해야 합니다. (Popper 포함)

\*\*`src/main.jsx`\*\*에 CSS/JS를 임포트하세요.

```jsx
// src/main.jsx
import React from 'react'
import ReactDOM from 'react-dom/client'
import App from './App.jsx'

// Bootstrap CSS & JS (bundle: Popper 포함)
import 'bootstrap/dist/css/bootstrap.min.css'
import 'bootstrap/dist/js/bootstrap.bundle.min.js'

ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>,
)
```

---

## 5) 핵심 체크포인트

* **class → className**: React에서는 `class` 대신 `className` 사용.
* **JS 컴포넌트는 bundle 필요**: 모달/드롭다운/툴팁 등은 `bootstrap.bundle.min.js`가 로드되어야 이벤트가 동작.
* **컨테이너/그리드**: `.container` → `.row` → `.col-*` 구조로 반응형 레이아웃 구성.
* **접근성 속성**: `aria-*` 속성, 버튼의 `aria-controls`/`aria-expanded` 등 신경 쓰기.

---

## 6) (선택) CDN으로 빠르게 시작하기

로컬 설치 대신 **CDN**을 쓰고 싶다면 `index.html`의 `<head>`에 CSS, `<body>` 끝에 JS 번들을 추가할 수도 있습니다. (프로덕션에선 NPM 관리 권장)

```html
<!-- head 안 -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">

<!-- body 끝 직전 -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
```

Vite 환경에서는 NPM 설치 후 `main.jsx`에서 임포트하는 방식이 가장 깔끔합니다.
