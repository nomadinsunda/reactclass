

## ✅ npx 란?

> `npx`는 **npm 패키지를 설치하지 않고도 바로 실행할 수 있게 해주는 명령어 도구**입니다.

---

## ✅ npx는 왜 필요한가?

예를 들어 어떤 명령어(`serve`, `create-react-app`, `eslint`, `vite` 등)를 쓰고 싶은데:

* 로컬에 설치하긴 싫고
* 1회성 실행만 하고 싶다면

바로 이렇게 사용합니다:

```bash
npx serve
```

➡ 이 명령어는 다음을 자동으로 해줍니다:

1. npm 레지스트리에서 `serve` 패키지 다운로드
2. 임시로 실행
3. 실행 끝나면 삭제 (로컬에 남지 않음)

---

## ✅ 예시

| 명령어                          | 설명                  |
| ---------------------------- | ------------------- |
| `npx create-react-app myapp` | React 앱을 빠르게 생성     |
| `npx eslint .`               | 프로젝트 전체를 ESLint로 검사 |
| `npx vite`                   | Vite 개발 서버 실행       |
| `npx serve -s .`             | 정적 파일을 로컬 서버로 제공    |

---

## ✅ npx vs npm install

| 비교 항목  | `npx`     | `npm install`                |
| ------ | --------- | ---------------------------- |
| 설치 여부  | ❌ 설치 안 함  | ✅ 설치함 (`node_modules`에)      |
| 디스크 사용 | 없음        | 있음                           |
| 실행 방법  | 바로 실행됨    | 설치 후 `npx` 또는 `npm run`으로 실행 |
| 주로 언제? | 1회성 도구 실행 | 프로젝트 내에 지속적으로 쓸 때            |

---

## ✅ 언제 유용한가?

* 테스트용으로 패키지 잠깐 쓸 때
* 최신 버전 실행하고 싶을 때
* 글로벌 설치가 번거로울 때

---

## ✅ 요약

| 질문       | 답변                                                 |
| -------- | -------------------------------------------------- |
| `npx`란?  | npm 패키지를 **설치 없이 실행**해주는 도구                        |
| 설치되나요?   | ❌ 설치되지 않고, 임시로 실행                                  |
| 어디에 쓰나요? | `create-react-app`, `vite`, `serve` 같은 실행형 패키지에 사용 |
