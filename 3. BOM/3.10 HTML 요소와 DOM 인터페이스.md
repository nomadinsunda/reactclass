# HTML 요소와 DOM 인터페이스

## 1. HTML 태그와 DOM 객체는 다르다

HTML 문서에 작성하는 다음 코드는 **HTML 소스 코드**입니다.

```html
<input type="text">
<button>확인</button>
<div>Hello</div>
```

브라우저는 HTML을 파싱하면서 각 요소에 대응하는 **DOM 객체를 생성**합니다.

```text
HTML Source
     │
     │ HTML Parser
     ▼
DOM Tree
     │
     ├─ <input>  → HTMLInputElement 객체
     ├─ <button> → HTMLButtonElement 객체
     └─ <div>    → HTMLDivElement 객체
```

따라서 `<input>` 자체가 `HTMLInputElement`라는 뜻이 아니라,

> 브라우저가 `<input>` 요소를 DOM에서 표현하기 위해 생성한 객체가 `HTMLInputElement` 인터페이스를 구현한 객체입니다.

---

## 2. 요소마다 대응하는 DOM 인터페이스가 있다

대표적인 요소를 보면 다음과 같습니다.

| HTML 요소      | 대응하는 DOM 인터페이스        |
| ------------ | --------------------- |
| `<input>`    | `HTMLInputElement`    |
| `<button>`   | `HTMLButtonElement`   |
| `<div>`      | `HTMLDivElement`      |
| `<form>`     | `HTMLFormElement`     |
| `<img>`      | `HTMLImageElement`    |
| `<a>`        | `HTMLAnchorElement`   |
| `<textarea>` | `HTMLTextAreaElement` |
| `<select>`   | `HTMLSelectElement`   |
| `<video>`    | `HTMLVideoElement`    |
| `<canvas>`   | `HTMLCanvasElement`   |

예를 들어:

```html
<input id="username" type="text">
```

브라우저가 DOM을 생성하면 개념적으로:

```text
<input id="username">
        │
        │ HTML Parsing
        ▼
┌─────────────────────────┐
│ HTMLInputElement 객체    │
│                         │
│ id: "username"          │
│ type: "text"            │
│ value: ""               │
│                         │
│ focus()                 │
│ blur()                  │
│ click()                 │
│ ...                     │
└─────────────────────────┘
```

가 됩니다.

# 3. JavaScript가 가져오는 것도 이 DOM 객체다

다음 코드를 생각해 봅시다.

```html
<input id="username" type="text">
```

JavaScript에서:

```js
const input = document.querySelector('#username');
```

`input` 변수에 HTML 문자열이 저장되는 것이 아닙니다.

```text
document.querySelector('#username')
               │
               ▼
        DOM Tree에서 검색
               │
               ▼
        HTMLInputElement 객체
               │
               ▼
             input
```

따라서 다음 코드가 가능합니다.

```js
input.value;
input.focus();
input.blur();
input.click();
```

확인해 보면:

```js
console.log(input instanceof HTMLInputElement);
```

결과:

```text
true
```

입니다.

---

# 4. 왜 요소마다 다른 인터페이스가 필요한가?

이 부분이 중요합니다.

`<input>`과 `<img>`는 할 수 있는 일이 서로 다릅니다.

예를 들어 `<input>`에는:

```js
input.value
input.checked
input.select()
```

같은 기능이 필요합니다.

반면 `<img>`에는:

```js
img.src
img.width
img.height
img.complete
```

같은 기능이 필요합니다.

따라서 브라우저는 각각 다른 DOM 인터페이스를 제공합니다.

```text
<input>
   │
   ▼
HTMLInputElement
   ├─ value
   ├─ checked
   ├─ select()
   └─ ...

<img>
   │
   ▼
HTMLImageElement
   ├─ src
   ├─ width
   ├─ height
   ├─ complete
   └─ ...
```

# 5. 그렇다고 완전히 별개의 객체는 아니다

여기서 DOM 객체의 **상속 구조**를 같이 설명하면 학생들이 훨씬 깊게 이해할 수 있습니다.

`HTMLInputElement`는 혼자 존재하는 것이 아닙니다.

대략적인 상속 관계는:

```text
EventTarget
    ▲
    │
   Node
    ▲
    │
 Element
    ▲
    │
HTMLElement
    ▲
    │
HTMLInputElement
```

즉 `<input>`의 실제 DOM 객체는 `HTMLInputElement`이면서 동시에:

```text
HTMLInputElement
       is a
HTMLElement
       is a
Element
       is a
Node
       is an
EventTarget
```

입니다.

그래서 실제로:

```js
const input = document.querySelector('input');

console.log(input instanceof HTMLInputElement); // true
console.log(input instanceof HTMLElement);      // true
console.log(input instanceof Element);          // true
console.log(input instanceof Node);             // true
console.log(input instanceof EventTarget);      // true
```

가 됩니다.

# 6. 상위 인터페이스에서 공통 기능을 물려받는다

이 상속 구조가 중요한 이유는 **공통 기능을 상위 인터페이스가 제공하기 때문**입니다.

예를 들어:

```text
EventTarget
    │
    └─ addEventListener()
             ▲
             │
Node
    │
    ├─ parentNode
    ├─ childNodes
    └─ ...
             ▲
             │
Element
    │
    ├─ classList
    ├─ getAttribute()
    ├─ querySelector()
    └─ ...
             ▲
             │
HTMLElement
    │
    ├─ style
    ├─ hidden
    ├─ click()
    └─ ...
             ▲
             │
HTMLInputElement
    │
    ├─ value
    ├─ checked
    ├─ type
    └─ select()
```

그래서 `HTMLInputElement` 객체에서:

```js
input.addEventListener(...)
input.parentNode
input.classList
input.style
input.value
```

를 모두 사용할 수 있습니다.

각 기능의 출처가 서로 다른 것입니다.

# 7. `<div>`도 같은 원리다

```html
<div id="box">Hello</div>
```

JavaScript에서:

```js
const box = document.querySelector('#box');
```

`box`는:

```text
HTMLDivElement 객체
```

입니다.

상속 구조는:

```text
EventTarget
    ▲
   Node
    ▲
 Element
    ▲
HTMLElement
    ▲
HTMLDivElement
```

따라서:

```js
box.addEventListener('click', ...);
box.classList.add('active');
box.style.color = 'red';
```

같은 기능을 사용할 수 있습니다.

# 8. React의 `ref`와 연결하면

이제 앞에서 배운 React `ref`가 정확하게 연결됩니다.

```jsx
const inputRef = useRef(null);

return (
  <input ref={inputRef} />
);
```

처음에는:

```text
inputRef
┌────────────────┐
│ current: null  │
└────────────────┘
```

React가 Commit Phase에서 실제 DOM을 연결하면:

```text
<input ref={inputRef} />
          │
          │ React Commit Phase
          ▼
실제 <input> DOM 객체 생성/연결
          │
          │
          ▼
┌───────────────────────────┐
│ HTMLInputElement 객체      │
│                           │
│ value                     │
│ type                      │
│ focus()                   │
│ blur()                    │
│ ...                       │
└───────────────────────────┘
          ▲
          │ 참조
          │
inputRef.current
```

따라서:

```js
inputRef.current.value
```

에서 `value`를 사용할 수 있는 이유는 `current`가 가리키는 실제 DOM 객체가 **`HTMLInputElement`이기 때문**입니다.

# 9. 가장 중요한 개념

학생들에게는 다음 세 가지를 반드시 구분시키는 것이 좋습니다.

```text
① HTML Source

<input type="text">
        │
        │ Browser HTML Parser
        ▼

② DOM

HTMLInputElement 객체
        │
        │ JavaScript가 참조
        ▼

③ JavaScript / React

document.querySelector('input')
또는
inputRef.current
```

즉,

> **HTML 태그는 문서에 작성된 마크업이고, 브라우저는 이를 파싱하여 각 HTML 요소에 대응하는 DOM 객체를 생성한다. `<input>`의 경우 그 DOM 객체가 `HTMLInputElement` 인터페이스를 구현한다. JavaScript와 React의 `ref`가 실제로 접근하는 대상은 이 DOM 객체다.**
