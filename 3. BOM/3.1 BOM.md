# Browser Object Model(BOM)

웹 브라우저에서 JavaScript를 제대로 이해하려면 **DOM(Document Object Model)** 뿐 아니라 **BOM(Browser Object Model)** 도 함께 이해해야 합니다.

가장 먼저 핵심을 잡으면 다음과 같습니다.

> **BOM(Browser Object Model)은 JavaScript가 브라우저 환경과 상호작용할 수 있도록 브라우저가 제공하는 객체와 API들을 개념적으로 묶어 부르는 용어입니다.**

여기서 중요한 점은 **BOM이 DOM처럼 하나의 공식 표준 이름으로 명확하게 정의된 단일 객체 모델은 아니라는 것**입니다. 현대 웹에서는 과거 BOM이라고 부르던 기능 대부분이 HTML Living Standard, DOM Standard, Web APIs 등의 여러 표준에 나뉘어 정의되어 있습니다.

---

# 1. JavaScript와 브라우저

JavaScript 언어 자체인 ECMAScript에는 다음과 같은 기능이 없습니다.

```javascript
window
document
location
history
navigator
alert()
setTimeout()
localStorage
```

ECMAScript가 정의하는 것은 예를 들면 다음과 같은 것들입니다.

```javascript
Object
Array
Map
Set
Promise
Function
String
Number
Date
Math
JSON
```

반면 브라우저는 JavaScript가 웹 환경에서 동작할 수 있도록 여러 **Host API**를 제공합니다.

전체 구조를 단순화하면 다음처럼 볼 수 있습니다.

```text
┌───────────────────────────────────────────────┐
│                Web Browser                    │
│                                               │
│   ┌───────────────────────────────────────┐   │
│   │              window                   │   │
│   │                                       │   │
│   │  document       location              │   │
│   │  navigator      history               │   │
│   │  screen         localStorage          │   │
│   │  sessionStorage                       │   │
│   │                                       │   │
│   │  alert()        confirm()             │   │
│   │  setTimeout()   setInterval()         │   │
│   │  requestAnimationFrame()              │   │
│   └───────────────────────────────────────┘   │
│                                               │
└───────────────────────────────────────────────┘
```

전통적으로 이러한 **브라우저 관련 객체와 기능을 묶어서 BOM이라고 설명**합니다.

---

# 2. BOM의 중심은 `window`

브라우저의 일반적인 웹페이지 환경에서 BOM을 이해할 때 가장 중요한 객체는 `window`입니다.

```javascript
console.log(window);
```

`window`는 현재 브라우저의 **브라우징 컨텍스트(browsing context)**에 연결된 `Window` 객체입니다.

쉽게 말하면 일반적인 탭의 웹페이지에서 JavaScript가 브라우저 기능에 접근하는 **최상위 진입점**이라고 볼 수 있습니다.

```text
window
 │
 ├── document
 │
 ├── location
 │
 ├── history
 │
 ├── navigator
 │
 ├── screen
 │
 ├── localStorage
 │
 ├── sessionStorage
 │
 ├── console
 │
 ├── alert()
 │
 ├── setTimeout()
 │
 └── requestAnimationFrame()
```

따라서 다음 코드가 가능합니다.

```javascript
window.alert("Hello");
window.setTimeout(...);
window.location;
window.document;
```

---

# 3. `window`는 브라우저 환경의 전역 객체

브라우저 메인 스레드의 일반적인 JavaScript에서는 `window`가 전역 객체 역할을 합니다.

```javascript
console.log(window === globalThis);
// true
```

그리고 `window`의 프로퍼티는 일반적으로 `window.`를 생략해서 접근할 수 있습니다.

```javascript
window.alert("Hello");
```

를 다음처럼 작성합니다.

```javascript
alert("Hello");
```

마찬가지로

```javascript
window.document
window.location
window.navigator
window.console
```

를 보통

```javascript
document
location
navigator
console
```

이라고 사용합니다.

따라서 개발자가 `window`를 직접 작성하지 않는다고 해서 `window`가 관계없는 것이 아닙니다.

---

# 4. BOM과 DOM의 관계

학생들이 가장 많이 혼동하는 부분입니다.

## BOM

브라우저 자체 및 브라우저 환경과 상호작용하기 위한 기능을 설명할 때 사용하는 개념입니다.

예:

```text
window
location
history
navigator
screen
localStorage
sessionStorage
```

## DOM

HTML/XML 문서를 **객체 트리로 표현한 모델**입니다.

예를 들어 다음 HTML이 있다면

```html
<body>
    <h1>Hello</h1>
    <button>Login</button>
</body>
```

브라우저는 이를 DOM 객체 구조로 표현합니다.

```text
Document
   │
   └── html
        │
        └── body
             ├── h1
             └── button
```

JavaScript에서는 `document`를 통해 DOM에 접근합니다.

```javascript
document.querySelector("h1");
```

중요한 관계는 다음입니다.

```text
Browser Environment
        │
      window
        │
        ├───────────────┐
        │               │
     document        location
        │            history
       DOM           navigator
        │            screen
        ▼
 HTML Document
```

즉,

> **`document`는 `window`를 통해 접근할 수 있는 객체이며, 그 `document`를 통해 현재 문서의 DOM에 접근합니다.**

```javascript
window.document === document
// true
```

---

# 5. `window.document`

`document`는 현재 `Window`에 연결된 웹 문서를 나타냅니다.

```javascript
console.log(window.document);
```

일반적으로는 다음처럼 사용합니다.

```javascript
document.querySelector("#login");
document.createElement("div");
document.body;
document.head;
```

따라서 DOM 조작은 대부분 `document`에서 시작합니다.

```javascript
const button = document.querySelector("#login");

button.addEventListener("click", () => {
    console.log("clicked");
});
```

구조적으로 보면

```text
window
  │
  └── document
        │
        └── DOM Tree
              │
              ├── html
              ├── head
              └── body
```

입니다.

---

# 6. `window.location`

`location`은 현재 문서의 URL과 관련된 정보를 나타냅니다.

예를 들어 현재 주소가

```text
https://example.com/products?id=10#review
```

라면 다음과 같은 정보를 얻을 수 있습니다.

```javascript
location.href
location.protocol
location.hostname
location.port
location.pathname
location.search
location.hash
```

개념적으로는 다음과 같습니다.

```text
https://example.com:443/products?id=10#review
  │          │      │       │       │
protocol   hostname port   search   hash
                         ↑
                      pathname
```

그리고 페이지 이동도 가능합니다.

```javascript
location.href = "https://example.com";
```

또는

```javascript
location.assign("/login");
```

현재 페이지를 다시 불러오는 것도 가능합니다.

```javascript
location.reload();
```

---

# 7. `window.history`

`history`는 현재 탭의 **세션 히스토리(session history)**를 다루기 위한 인터페이스입니다.

사용자가 다음 순서로 이동했다고 생각해봅시다.

```text
Google
   ↓
News
   ↓
Product
```

현재 Product 페이지에 있다면

```javascript
history.back();
```

으로 이전 페이지 방향으로 이동할 수 있고,

```javascript
history.forward();
```

로 다음 방향으로 이동할 수 있습니다.

```javascript
history.go(-2);
```

처럼 상대적인 이동도 가능합니다.

SPA에서는 특히 다음 API가 중요합니다.

```javascript
history.pushState()
history.replaceState()
```

React Router 같은 클라이언트 사이드 라우팅을 이해할 때도 관련되는 개념입니다.

---

# 8. `window.navigator`

`navigator`는 현재 브라우저 환경 및 사용자 에이전트와 관련된 여러 정보를 제공합니다.

```javascript
console.log(navigator);
```

대표적으로

```javascript
navigator.language
navigator.languages
navigator.onLine
navigator.userAgent
navigator.cookieEnabled
```

등이 있습니다.

그리고 현대 브라우저에서는 여러 Web API로 들어가는 진입점 역할도 합니다.

예:

```javascript
navigator.geolocation
navigator.clipboard
navigator.mediaDevices
```

예를 들어 클립보드에 문자열을 복사하려면

```javascript
navigator.clipboard.writeText("Hello");
```

처럼 사용할 수 있습니다.

다만 `navigator`가 제공하는 기능 중에는 **HTTPS, 사용자 권한, 브라우저 정책 등의 제약**을 받는 API가 많습니다.

---

# 9. `window.screen`

`screen`은 사용자의 디스플레이 화면에 관한 정보를 제공합니다.

```javascript
screen.width
screen.height

screen.availWidth
screen.availHeight

screen.colorDepth
screen.pixelDepth
```

주의할 점은 `screen`이 **브라우저 창 크기**를 의미하지 않는다는 것입니다.

```text
Physical / logical Screen
┌────────────────────────────────────┐
│                                    │
│       Browser Window               │
│       ┌────────────────────┐       │
│       │                    │       │
│       │      Web Page      │       │
│       │                    │       │
│       └────────────────────┘       │
│                                    │
└────────────────────────────────────┘
```

브라우저 viewport 크기를 알아보려면 보통

```javascript
window.innerWidth
window.innerHeight
```

를 사용합니다.

---

# 10. 브라우저 창의 크기와 위치

`window`는 현재 창과 관련된 정보도 제공합니다.

```javascript
window.innerWidth
window.innerHeight
```

이는 일반적으로 **viewport의 내부 크기**를 나타냅니다.

```javascript
window.outerWidth
window.outerHeight
```

는 브라우저 창 전체 크기와 관련됩니다.

또한 스크롤 위치도 확인할 수 있습니다.

```javascript
window.scrollX
window.scrollY
```

그리고

```javascript
window.scrollTo(0, 500);
```

처럼 페이지를 이동시킬 수도 있습니다.

---

# 11. 대화상자 API

전통적인 BOM 설명에서 빠지지 않는 기능입니다.

### alert

```javascript
alert("로그인이 완료되었습니다.");
```

### confirm

```javascript
const result = confirm("삭제하시겠습니까?");
```

사용자의 선택에 따라 `boolean`이 반환됩니다.

```javascript
true
false
```

### prompt

```javascript
const name = prompt("이름을 입력하세요.");
```

이러한 대화상자는 브라우저가 제공하는 기능이지 ECMAScript 자체의 기능이 아닙니다.

---

# 12. Timer API

다음 역시 브라우저 환경에서 매우 중요한 API입니다.

```javascript
setTimeout()
setInterval()
clearTimeout()
clearInterval()
```

예를 들어

```javascript
setTimeout(() => {
    console.log("2초 후 실행");
}, 2000);
```

여기서 아주 중요한 사실이 있습니다.

> **`setTimeout()`은 JavaScript 엔진 자체가 제공하는 기능이 아닙니다.**

브라우저 환경이 제공하는 API입니다.

개념적으로 보면

```text
JavaScript
   │
   │ setTimeout(callback, 2000)
   ▼
Browser Timer API
   │
   │ 2 seconds
   ▼
Task Queue
   │
   ▼
Event Loop
   │
   ▼
Call Stack
   │
   ▼
callback()
```

이 구조를 이해하면 JavaScript의 **이벤트 루프와 비동기 처리**도 훨씬 이해하기 쉬워집니다.

---

# 13. `requestAnimationFrame()`

브라우저 화면 갱신과 동기화하여 애니메이션 코드를 실행하기 위한 API입니다.

```javascript
requestAnimationFrame(callback);
```

예:

```javascript
function animate() {
    console.log("animation");

    requestAnimationFrame(animate);
}

requestAnimationFrame(animate);
```

일반적인 웹 애니메이션에서는 무조건 `setInterval()`을 사용하는 것보다 `requestAnimationFrame()`이 브라우저 렌더링 주기와 연결되어 있다는 점이 중요합니다.

---

# 14. Web Storage

브라우저는 데이터를 클라이언트 측에 저장할 수 있는 Web Storage API도 제공합니다.

대표적으로

```javascript
localStorage
sessionStorage
```

가 있습니다.

### localStorage

```javascript
localStorage.setItem("username", "Alice");

const name = localStorage.getItem("username");

localStorage.removeItem("username");
```

브라우징 세션을 넘어서 데이터가 유지될 수 있습니다.

### sessionStorage

```javascript
sessionStorage.setItem("token", "1234");
```

해당 탭의 페이지 세션을 중심으로 데이터를 유지합니다.

단순히

> `localStorage = 영구 저장`, `sessionStorage = 브라우저 닫으면 삭제`

라고만 암기하면 세부 동작을 잘못 이해할 수 있으므로, 실제로는 **origin과 브라우징 컨텍스트/페이지 세션의 범위**를 함께 이해하는 것이 좋습니다.

---

# 15. `window.open()`과 창 제어

새로운 브라우징 컨텍스트를 열 수도 있습니다.

```javascript
const newWindow = window.open(
    "https://example.com",
    "_blank"
);
```

반환된 `Window` 참조를 통해 허용되는 범위에서 새 창과 상호작용할 수 있습니다.

```javascript
newWindow.close();
```

하지만 현대 브라우저에서는 팝업 차단, Same-Origin Policy 등의 보안 정책 때문에 자유롭게 사용할 수 있는 것은 아닙니다.

---

# 16. 브라우저 이벤트

`window` 자체도 `EventTarget` 계열의 이벤트 처리 기능을 제공합니다.

```javascript
window.addEventListener("resize", () => {
    console.log(window.innerWidth);
});
```

스크롤 이벤트:

```javascript
window.addEventListener("scroll", () => {
    console.log(window.scrollY);
});
```

페이지 로드:

```javascript
window.addEventListener("load", () => {
    console.log("페이지 리소스 로드 완료");
});
```

따라서 `window`는 단순히 여러 객체를 보관하는 컨테이너라고만 이해해서는 안 됩니다.

---

# 17. BOM을 객체 계층으로만 이해하면 안 되는 이유

과거 교육 자료에서는 BOM을 다음처럼 설명하는 경우가 많습니다.

```text
window
 ├── document
 ├── navigator
 ├── location
 ├── history
 └── screen
```

입문 단계에서는 유용하지만 **실제 표준 구조를 완전히 표현하는 그림은 아닙니다.**

예를 들어

```javascript
window.location
document.location
```

둘 다 사용할 수 있습니다.

또한 현대 웹 플랫폼에는

```text
Window
Document
Location
History
Navigator
Storage
Performance
Fetch API
WebSocket
Worker
IndexedDB
Clipboard API
Geolocation API
```

등 방대한 API가 있으며, 이것들을 모두 단순히 "`window` 밑에 있는 BOM 객체"라고 분류하는 것은 현대적인 관점에서는 지나치게 단순화된 설명입니다.

---

# 18. BOM은 공식적인 단일 표준 명칭인가?

이 부분이 교육할 때 특히 중요합니다.

**DOM은 공식 표준 개념입니다.**

반면 **BOM은 역사적으로 브라우저가 제공하는 DOM 이외의 객체들을 묶어 설명하기 위해 널리 사용된 용어**에 가깝습니다.

과거에는 브라우저마다 구현 차이가 컸습니다.

```text
JavaScript
     │
     ▼
Browser
     │
 ┌───┼───────────────┐
 │   │               │
DOM  Window       Browser APIs
 │   │               │
HTML Location      Storage
    History        Timers
    Navigator      Fetch
    Screen         ...
```

현대에는 이 기능들이 여러 웹 표준에 걸쳐 정의됩니다.

따라서 강의에서는 다음처럼 정의하는 것이 가장 안전합니다.

> **BOM(Browser Object Model)은 웹 브라우저가 JavaScript에 제공하는 브라우저 환경 관련 객체와 API들을 설명하기 위해 사용하는 전통적인 개념적 분류이다.**

이 정의가 "`BOM이라는 하나의 공식 객체 트리가 존재한다`"는 오해를 피할 수 있습니다.

---

# 19. DOM / BOM / ECMAScript를 구분하자

학생들에게는 다음 구분이 특히 중요합니다.

| 구분         | 역할                       | 대표적인 예                                                 |
| ---------- | ------------------------ | ------------------------------------------------------ |
| ECMAScript | JavaScript 언어 자체         | `Object`, `Array`, `Promise`, `Map`                    |
| DOM        | 문서를 객체 구조로 표현            | `Document`, `Element`, `Node`                          |
| BOM        | 브라우저 환경 관련 기능을 묶어 부르는 개념 | `Window`, `Location`, `History`, `Navigator`, `Screen` |
| Web APIs   | 브라우저가 제공하는 다양한 웹 기능      | Fetch, Storage, Clipboard, Geolocation 등               |

단, 이 표는 **교육적인 개념 분류**입니다. 실제 표준 명세의 경계가 이 표처럼 완벽하게 분리되어 있는 것은 아닙니다.

---

# 20. 전체 구조를 하나로 연결하면

JavaScript를 배우는 학생들에게는 다음 그림으로 연결해서 설명하는 것이 가장 직관적입니다.

```text
                     WEB BROWSER
┌─────────────────────────────────────────────────────┐
│                                                     │
│                       window                        │
│                         │                           │
│        ┌────────────────┼─────────────────┐         │

```

그리고 JavaScript 코드에서는

```javascript
// DOM
document.querySelector("#login");

// URL
location.href;

// History
history.back();

// Browser information
navigator.language;

// Screen
screen.width;

// Storage
localStorage.setItem("name", "Alice");

// Timer
setTimeout(() => {
    console.log("Hello");
}, 1000);

// Window event
window.addEventListener("resize", () => {
    console.log(window.innerWidth);
});
```

처럼 브라우저가 제공하는 기능을 사용합니다.

## 핵심 정리

BOM을 단순히 "`window`, `navigator`, `location`을 모아놓은 것"이라고 외우기보다는 다음 흐름으로 이해하는 것이 좋습니다.

```text
ECMAScript
    │
    │ JavaScript 언어 자체
    ▼
JavaScript 코드
    │
    │ 브라우저가 Host Environment 제공
    ▼
Web Platform
    │
    ├── Window
    ├── DOM
    ├── Location / History
    ├── Navigator / Screen
    ├── Storage
    ├── Timers
    ├── Fetch
    └── 기타 Web APIs
```

즉, **JavaScript는 언어이고, 브라우저는 실행 환경이며, 브라우저가 JavaScript에 제공하는 다양한 인터페이스 중 브라우저 환경 자체와 관련된 객체들을 전통적으로 BOM이라고 부릅니다.**

이 관점을 잡아두면 이후에 **`window` → DOM → CSSOM → Render Tree → Layout → Paint → Event Loop → Web APIs**로 연결해서 브라우저의 전체 동작 구조를 이해하기가 훨씬 쉬워집니다.
