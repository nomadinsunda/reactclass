
## ✅ `&copy;`란?

| 구분      | 설명                                                    |
| ------- | ----------------------------------------------------- |
| 의미      | "copyright"를 의미하는 **저작권 기호(©)**                       |
| HTML 코드 | `&copy;`                                              |
| 실제 출력   | `©` (복사권 기호)                                          |
| 유니코드    | `U+00A9`                                              |
| 사용 예    | `<p>&copy; 2025 React 프로젝트</p>` → `© 2025 React 프로젝트` |

---

## 🔍 왜 `&copy;`를 쓰나?

HTML에서는 일부 \*\*특수 문자(예: <, >, & 등)\*\*를 직접 쓰면 브라우저가 HTML 태그로 오해할 수 있습니다.

그래서 다음과 같은 \*\*문자 엔티티(Entity)\*\*를 사용합니다:

| 문자  | 엔티티 코드   | 의미                   |
| --- | -------- | -------------------- |
| `<` | `&lt;`   | less than            |
| `>` | `&gt;`   | greater than         |
| `&` | `&amp;`  | ampersand            |
| `©` | `&copy;` | copyright            |
| `®` | `&reg;`  | registered trademark |

---

## 🎯 React에서는 그냥 `©` 써도 되나요?

네, React의 JSX에서는 **UTF-8 문자 인코딩이 적용**되므로 **`©`를 직접 써도 됩니다.**

예:

```jsx
<footer>
  <p>© 2025 React 예제</p>   // ✅ OK
</footer>
```

하지만 HTML 특성을 강조하거나, HTML 강의/문서처럼 의도적으로 **명시적 표현을 원할 경우** `&copy;`를 쓸 수도 있습니다.

---

## ✅ 결론

| 방식       | 사용 예                 | 권장 여부              |
| -------- | -------------------- | ------------------ |
| `&copy;` | `<p>&copy; 2025</p>` | HTML에서 자주 사용됨      |
| `©`      | `<p>© 2025</p>`      | JSX에서 사용 가능, 더 직관적 |
