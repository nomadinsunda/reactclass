```html
<link rel="icon" type="image/svg+xml" href="/vite.svg" />
```

는 웹사이트의 **파비콘(favicon)** 을 설정하는 것입니다.

---

# 🖼️ `<link rel="icon">`란?

## ✅ 정의

```html
<link rel="icon" href="..." />
```

는 웹 브라우저의 **탭, 북마크, 히스토리** 등에서 표시되는
\*\*웹사이트의 작은 아이콘 (favicon)\*\*을 지정하는 태그입니다.

---

## 🔍 태그 구성 해설

```html
<link 
  rel="icon" 
  type="image/svg+xml" 
  href="/vite.svg" 
/>
```

| 속성                     | 의미                                |
| ---------------------- | --------------------------------- |
| `rel="icon"`           | 이 요소가 "파비콘(favicon)"임을 나타냄        |
| `type="image/svg+xml"` | 아이콘의 MIME 타입 → **SVG 벡터 이미지**라는 뜻 |
| `href="/vite.svg"`     | 아이콘 이미지 파일 경로 (루트 디렉터리 기준)        |

---

## 🧠 어떻게 작동하는가?

1. 브라우저는 HTML 문서를 파싱할 때 `<link rel="icon">`을 확인
2. 해당 경로(`/vite.svg`)의 이미지를 다운로드
3. 다음 위치에 표시함:

   * 브라우저 탭 왼쪽 (🧠 사용자가 열어본 사이트인지 인식)
   * 북마크 아이콘
   * 검색/주소창 자동완성 추천 시 아이콘
   * 모바일 홈화면 아이콘 (일부)

---

## 🎨 SVG를 사용하는 이유

| SVG (Scalable Vector Graphics) | 장점                        |
| ------------------------------ | ------------------------- |
| **확대/축소 시 깨지지 않음**             | 다양한 해상도 대응 가능             |
| **파일 크기 작음**                   | 코드로 구성된 벡터 기반             |
| **다크모드/테마 반응형 적용 가능**          | CSS나 JavaScript로 동적 제어 가능 |
| **해상도 독립적**                    | Retina/4K 화면에도 선명하게 표현    |

> 이전에는 `.ico`나 `.png`가 기본이었지만,
> 최신 웹에서는 **`SVG` 아이콘이 표준으로 확산 중**입니다.

---

## 📁 `/vite.svg`는 어디 있나?

* Vite 프로젝트의 루트에 기본적으로 생성되는 `public/vite.svg` 파일입니다.
* 실제 브라우저 요청은 다음 경로로 이동합니다:

```
http://localhost:5173/vite.svg
```

즉, `public/` 디렉터리에 넣어 두면 해당 파일은 **Vite dev server에 의해 정적 파일로 서빙됩니다.**

## ✅ 정리 요약

| 항목    | 설명                                       |
| ----- | ---------------------------------------- |
| 목적    | 브라우저 탭/북마크/홈화면 등에 표시될 **아이콘 설정**         |
| rel   | `"icon"`으로 고정 (역할: 파비콘)                  |
| type  | MIME 타입 (`image/svg+xml`, `image/png` 등) |
| href  | 아이콘 파일의 URL (보통 `public/` 경로 기준)         |
| 사용 이유 | 브랜드 인식, UX 향상, 모바일 홈화면 대응 등              |
