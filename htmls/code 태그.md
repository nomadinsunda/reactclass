

# ✅ `<code>` 태그

## 📌 1. 정의

```html
<p>다음은 <code>console.log('Hello, world!')</code> 예제입니다.</p>
```

* `<code>`는 **HTML 문서 내에서 컴퓨터 코드임을 명시**하는 인라인 시맨틱 태그입니다.
* 기본적으로 **고정폭 글꼴(monospaced font)** 으로 표시됩니다.
* 시맨틱 웹을 구성하는 데 중요한 역할을 하며, 스크린리더와 같은 보조 기술에도 의미가 전달됩니다.

---

## 🔧 2. 주요 특징

| 속성          | 설명                                             |
| ----------- | ---------------------------------------------- |
| 전역 속성 사용 가능 | `id`, `class`, `style`, `data-*` 등             |
| 콘텐츠 모델      | **인라인 요소**(inline element)                     |
| 기본 스타일      | 보통 `monospace` 폰트 (예: Consolas, Courier New 등) |
| 중첩 가능       | `<code>` 태그 내부에 다른 태그 포함 가능 (제한적으로)            |

---

## 🧠 3. 사용 목적

* 명령어, 코드 한 줄, 변수 이름 등을 시각적으로 강조할 때 사용
* 스크립트나 CLI 명령어, HTML 태그 등을 설명하는 문서에서 자주 사용

```html
<p>리눅스에서 <code>ls -al</code> 명령어를 사용합니다.</p>
<p>자바스크립트에서 <code>let x = 10;</code> 과 같이 선언합니다.</p>
```

---

## 🧩 4. `<pre>`와의 차이점

| 항목        | `<code>`                     | `<pre>`                       |
| --------- | ---------------------------- | ----------------------------- |
| 용도        | **코드 조각 한 줄** 또는 부분 강조       | **형식 보존 전체 코드 블록**            |
| 개행, 공백 유지 | ❌ (브라우저가 줄바꿈/공백 무시)          | ✅ (형식 그대로 유지됨)                |
| 대표 사용     | `<code>console.log()</code>` | `<pre><code>...</code></pre>` |

✅ **둘을 함께 사용하는 것이 일반적**입니다:

```html
<pre><code>
function greet() {
  console.log('Hello');
}
</code></pre>
```

---

## 🎨 5. 스타일링 예시 (CSS)

```css
code {
  font-family: Consolas, monospace;
  background-color: #f4f4f4;
  padding: 2px 4px;
  border-radius: 4px;
}
pre code {
  display: block;
  padding: 1em;
  overflow-x: auto;
}
```

---

## ✨ 6. 실전 사용 예시

### ✅ 코드 일부 강조

```html
<p>변수 선언은 <code>let</code> 또는 <code>const</code>를 사용하세요.</p>
```

### ✅ 전체 코드 블록

```html
<pre><code>
for (let i = 0; i < 10; i++) {
  console.log(i);
}
</code></pre>
```

---

## 🧠 접근성과 시맨틱 의미

* `<code>`는 시맨틱 태그로, **스크린 리더가 '코드입니다'라고 인식**합니다.
* 따라서 디자인만 비슷하게 `<span>`으로 구현하는 것보다 `<code>`가 **접근성과 의미 전달 측면에서 우수**합니다.

---

## ⚠️ 주의 사항

* `<code>`는 인라인 요소이기 때문에 여러 줄 코드나 들여쓰기를 표현할 수 없음 → **`<pre>`와 함께 사용** 필요
* 내부에 HTML 태그를 넣을 경우, 실제 코드 표현을 위해 **HTML 이스케이프 처리**가 필요:

```html
<code>&lt;div class="box"&gt;&lt;/div&gt;</code>
```

## ✅ 요약

| 항목         | 설명                                                 |
| ---------- | -------------------------------------------------- |
| 태그         | `<code>`                                           |
| 목적         | 코드 조각, 명령어, 변수 등을 의미적으로 표시                         |
| 기본 스타일     | 고정폭 글꼴 (monospace)                                 |
| 인라인 요소     | 예 (줄바꿈 안 됨)                                        |
| 전체 코드 표시   | `<pre><code>...</code></pre>` 구조 추천                |
| 접근성        | 스크린리더 지원 우수                                        |
| React 사용 시 | `<code>{\`const x = 10;\`}</code>\` 와 같이 JSX 사용 가능 |
