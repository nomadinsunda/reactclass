
## ✅ 1. `<ul>` : **순서 없는 목록 (Unordered List)**

* **용도**: 항목 간 **순서가 중요하지 않을 때** 사용
* **기본 스타일**: 항목 앞에 ●, ○ 같은 **불릿 기호**
* **예시**:

  ```html
  <ul>
    <li>사과</li>
    <li>바나나</li>
    <li>포도</li>
  </ul>
  ```

  **브라우저 출력**:

  * ● 사과
  * ● 바나나
  * ● 포도

---

## ✅ 2. `<ol>` : **순서 있는 목록 (Ordered List)**

* **용도**: 항목 간에 **순서가 중요한 경우** 사용 (예: 단계, 절차)

* **기본 스타일**: 1, 2, 3... 또는 i, ii, iii...

* **예시**:

  ```html
  <ol>
    <li>문 열기</li>
    <li>들어가기</li>
    <li>문 닫기</li>
  </ol>
  ```

  **브라우저 출력**:

  1. 문 열기
  2. 들어가기
  3. 문 닫기

* **속성 사용 예 (타입 바꾸기)**:

  ```html
  <ol type="A">   <!-- A, B, C... -->
  <ol type="a">   <!-- a, b, c... -->
  <ol type="I">   <!-- I, II, III... -->
  <ol start="5">  <!-- 5부터 시작 -->
  ```

---

## ✅ 3. `<li>` : **목록 항목 (List Item)**

* `li`는 **"list item"** (목록 항목)의 줄임말
* **`<ul>` 또는 `<ol>` 내부에서만** 사용 가능
* **각 항목을 표현하는 태그**
* **예시**:

  ```html
  <ul>
    <li>빨강</li>
    <li>파랑</li>
  </ul>

  <ol>
    <li>1단계</li>
    <li>2단계</li>
  </ol>
  ```

---

## 🔁 비교 요약

| 태그     | 설명       | 스타일       | 용도 예                   |
| ------ | -------- | --------- | ---------------------- |
| `<ul>` | 순서 없는 목록 | ●, ○ 등 불릿 | 네비게이션, 재료 목록           |
| `<ol>` | 순서 있는 목록 | 숫자 또는 문자  | 절차, 순위, 단계             |
| `<li>` | 목록 항목    | 목록 내부 아이템 | `<ul>` 또는 `<ol>` 안에 위치 |

## 🎨 추가: 스타일 변경 (CSS 예시)

```html
<ul style="list-style-type: square;">
  <li>HTML</li>
  <li>CSS</li>
  <li>JS</li>
</ul>

<ol style="list-style-type: upper-roman;">
  <li>Step One</li>
  <li>Step Two</li>
</ol>
```

* `list-style-type` 값:

  * `disc` (● 기본값)
  * `circle` (○)
  * `square` (■)
  * `none` (불릿 제거)
  * `decimal` (1, 2, 3)
  * `upper-roman` (I, II, III)
  * `lower-alpha` (a, b, c)
