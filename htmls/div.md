

## ✅ 먼저, 이렇게 생각해 보세요

HTML 웹페이지는 다양한 \*\*구역(영역)\*\*들로 이루어져 있습니다.

예를 들어:

```
┌────────────────────┐
│      헤더          │
├────────────────────┤
│      본문          │
├────────────────────┤
│      푸터          │
└────────────────────┘
```

이런 **구역을 나누는 상자**를 만드는 태그가 바로 `<div>`입니다.

---

## ✅ 예시로 보겠습니다

```html
<div>
  <h1>안녕하세요</h1>
  <p>이건 첫 번째 구역입니다.</p>
</div>
```

이 코드는 아래처럼 생각하시면 됩니다:

```
[박스]
  ├ 제목: 안녕하세요
  └ 내용: 이건 첫 번째 구역입니다.
```

여기서 `<div>`가 바로 **이 박스를 만드는 것**입니다.
화면에 보이지 않지만, **보이지 않는 상자**를 만드는 거예요.

---

## ✅ 왜 상자를 만들어야 할까요?

상자가 있으면, 거기에 **스타일을 입히거나**, **정렬**하거나, **자바스크립트로 제어**할 수 있습니다.

예를 들어:

```html
<div style="background-color: yellow;">
  <p>이 박스는 노란색입니다</p>
</div>
```

→ 이 코드는 화면에 **노란 배경을 가진 구역**을 만듭니다.

---

## ✅ 아주 쉬운 비유

* `<div>` = 투명한 박스
* 안에 넣고 싶은 내용을 담을 수 있음
* CSS로 꾸밀 수 있음
* 자바스크립트로 조작할 수 있음

---

## ✅ 실습 추천

아래 HTML을 복사해서 직접 브라우저에서 실행해보세요:

```html
<!DOCTYPE html>
<html>
  <head>
    <style>
      .box {
        width: 200px;
        height: 100px;
        background-color: lightblue;
        border: 2px solid navy;
      }
    </style>
  </head>
  <body>
    <div class="box">
      <p>이건 div 상자입니다!</p>
    </div>
  </body>
</html>
```

👆 이것이 바로 `<div>`가 하는 역할입니다.

---

## 더 궁금하신 점 있으신가요?

* `<div>`는 **눈에 안 보이는 상자**입니다.
* 그 안에 다른 HTML 요소들을 넣을 수 있습니다.
* CSS나 JS로 제어하기 쉬운 구조를 만들어 줍니다.

---


























## ✅ 1. `<div>` 태그란?

\*\*`<div>`\*\*는 HTML에서 \*\*"division(구획)"\*\*을 의미하며,
\*\*문서 내에서 하나의 \*\*영역(블록)\*\*을 나누기 위한 컨테이너 요소(container element)\*\*입니다.

---

## ✅ 2. 특징 요약

| 항목            | 설명                                                                       |
| ------------- | ------------------------------------------------------------------------ |
| 태그명           | `<div>`                                                                  |
| 의미            | "구획" 또는 "섹션"을 만들기 위한 **비의미적인 컨테이너**                                      |
| 기본 display 속성 | `block` (한 줄 전체 차지)                                                      |
| 내용            | 텍스트, 이미지, 다른 HTML 요소 등 어떤 것도 포함 가능                                       |
| 스타일링          | CSS를 통해 외형, 레이아웃 등을 지정                                                   |
| 자바스크립트 조작     | `document.querySelector`, `getElementById`, `addEventListener` 등으로 조작 가능 |

---

## ✅ 3. 왜 사용하는가?

### ✔ 레이아웃을 잡기 위해

```html
<div class="header">헤더</div>
<div class="content">본문</div>
<div class="footer">푸터</div>
```

### ✔ CSS 스타일을 적용하기 위해

```html
<div class="box">내용</div>

<style>
  .box {
    width: 200px;
    height: 100px;
    background-color: skyblue;
    border: 1px solid gray;
  }
</style>
```

### ✔ JavaScript 조작을 위한 구조로

```html
<div id="myDiv">클릭하세요</div>

<script>
  document.getElementById("myDiv").addEventListener("click", () => {
    alert("눌렸어요!");
  });
</script>
```

---

## ✅ 4. 의미 없는 태그? (Semantic Tag와의 비교)

| 태그                     | 의미      | 용도          |
| ---------------------- | ------- | ----------- |
| `<div>`                | ❌ 없음    | 단순 컨테이너     |
| `<section>`            | ✅ 의미 있음 | 주제 구획       |
| `<article>`            | ✅ 있음    | 독립적인 콘텐츠 단위 |
| `<header>`, `<footer>` | ✅ 있음    | 구조적인 의미 포함  |

**Semantic HTML**이 중요한 이유는 접근성(스크린 리더), SEO, 구조적 코드 작성 등 때문입니다.

> 그러므로:
> **의미 있는 콘텐츠에는 `<div>`보다 의미 태그 사용이 권장됨**
> 하지만 `<div>`는 여전히 **스타일링, 자바스크립트 대상**으로 매우 유용함

---

## ✅ 5. 자주 묻는 질문

### 📌 `<div>` 안에 `<p>`, `<ul>`, `<img>` 다 넣을 수 있어요?

> 네. `<div>`는 거의 모든 HTML 요소를 감쌀 수 있는 범용 컨테이너입니다.

### 📌 `<div>` 없이 레이아웃 만들 수 없나요?

> 최근에는 CSS Grid, Flexbox, Semantic HTML 태그들을 함께 사용하면 `<div>` 남용을 줄일 수 있습니다.

---

## ✅ 예제: React와 함께 사용하는 경우

```jsx
function App() {
  return (
    <div className="container">
      <h1>Hello</h1>
      <p>Welcome to React + Vite</p>
    </div>
  );
}
```

* `div`는 JSX 내에서 컴포넌트의 **루트 요소** 또는 **스타일 적용용 컨테이너**로 주로 사용됨

---

## ✅ 마무리

`<div>`는 HTML 문서에서 **가장 많이 사용되는 태그 중 하나**이며,
비록 의미는 없지만 **레이아웃 설계, 스타일링, 자바스크립트 조작을 위한 핵심 컨테이너**입니다.
