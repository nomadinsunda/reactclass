
# 🔗 Hyperlink란? (하이퍼링크)

## ✅ 정의

**Hyperlink(하이퍼링크)** 란,

> 한 문서에서 다른 문서나 문서의 특정 위치, 혹은 외부 리소스로 **이동하거나 연결할 수 있는 기능**입니다.

* "hyper"는 **비선형(nonlinear)** 을 의미하고,
* "link"는 **연결**을 의미합니다.
* 즉, 문서 간을 **순차적이 아닌 방식으로 자유롭게 연결**해주는 기술입니다.

---

## 🧠 더 쉽게 설명하면...

> 하이퍼링크는 **클릭 가능한 연결 고리**입니다.
> 사용자가 클릭하면 다른 페이지, 문서, 이미지, 이메일, 전화번호 등으로 이동할 수 있게 해줍니다.

---

## 📌 HTML에서의 예시

```html
<a href="https://example.com">Example 사이트로 이동</a>
```

* `href` 속성은 **Hypertext REFerence**, 즉 연결할 주소를 의미
* 이 `a` 태그는 사용자가 클릭하면 `https://example.com`으로 이동하게 합니다

---

## 🌐 종류

| 유형                   | 설명                  | 예시                           |
| -------------------- | ------------------- | ---------------------------- |
| **절대 링크**            | 전체 URL 주소를 사용       | `https://google.com`         |
| **상대 링크**            | 현재 문서를 기준으로 상대경로 지정 | `../about.html`              |
| **내부 링크 (Fragment)** | 같은 문서의 특정 위치로 이동    | `#section1`                  |
| **이메일 링크**           | 이메일 클라이언트를 열기       | `mailto:someone@example.com` |
| **전화 링크**            | 전화 앱 실행 (모바일)       | `tel:+821012345678`          |

---

## 🧩 하이퍼링크의 구성 요소

HTML에서 하이퍼링크는 일반적으로 `<a>` 태그로 작성되며, 다음 요소를 포함합니다:

* `href`: 이동할 대상
* `anchor text`: 사용자에게 보이는 텍스트
* `target`, `rel`: 링크 동작 방식 및 보안 설정

예시:

```html
<a href="https://vite.dev" target="_blank" rel="noopener noreferrer">Vite 공식 사이트</a>
```

## 🧠 기술적 중요성

| 측면          | 설명                                                   |
| ----------- | ---------------------------------------------------- |
| **UX**      | 사용자가 원하는 정보로 쉽게 이동 가능                                |
| **SEO**     | 검색 엔진이 페이지를 탐색할 때 하이퍼링크 구조를 기반으로 링크 구조를 분석           |
| **정보 구조**   | 웹은 하이퍼링크 기반의 **비선형 정보 구조**로 설계됨 (Web 1.0\~3.0 모두 해당) |
| **HTTP 동작** | 하이퍼링크를 클릭하면 브라우저는 해당 URL로 `GET` 요청을 보냄               |

---

## 🔄 웹의 핵심: 하이퍼텍스트 시스템

* 하이퍼링크는 **하이퍼텍스트(hypertext)** 시스템의 핵심 구성 요소입니다.
* 하이퍼텍스트: 텍스트 내에 다른 문서나 정보로의 링크를 포함하는 텍스트
* 웹은 하이퍼텍스트 기반으로 설계되어 있어, 하이퍼링크는 HTML의 **근본적인 기능 중 하나**입니다.
