# 📱 `<meta name="viewport">`란?

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

## ✅ 정의

`<meta name="viewport">`는

> **브라우저가 HTML 페이지를 모바일 화면에 어떻게 표시할지 제어하는 메타 태그**입니다.

즉, **모바일 디바이스에서 화면의 크기, 스케일(확대/축소), 렌더링 방식**을 결정합니다.

---

## ✅ 왜 필요한가?

### 💡 기본적으로 모바일 브라우저는 데스크톱 웹사이트를 **축소해서** 보여주려 합니다.

> 예전에는 모바일 디바이스가 웹사이트를 볼 때
> "화면 폭 = 980px"처럼 가정하고 페이지를 줄여 보여줬습니다.

이 때문에:

* 텍스트가 너무 작고
* 레이아웃이 깨지고
* 사용자 경험이 나빠졌습니다.

### 👉 해결 방법이 바로 `<meta name="viewport">`입니다.

---

## 📐 주요 속성

### ✅ `width=device-width`

* 장치의 실제 화면 폭에 맞게 페이지 폭을 설정합니다.
* 예: iPhone이면 약 375px, iPad는 약 768px 등
* 👉 **반응형 웹의 핵심 전제 조건**입니다.

### ✅ `initial-scale=1.0`

* \*\*초기 확대 비율(zoom level)\*\*을 1.0 (100%)로 설정합니다.
* 즉, 페이지를 실제 픽셀 기준으로 1:1 렌더링

---

## 📱 모바일 화면에서의 작동 예

### ✅ 있는 경우:

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

결과:

* 페이지가 **디바이스 화면 너비에 맞춰** 렌더링됨
* 글자 크기, 버튼 크기 등이 적절
* 미디어 쿼리 정상 작동

### ❌ 없는 경우:

```html
<!-- 없음 -->
```

결과:

* 디바이스가 보통 가로폭 980px로 가정
* 페이지가 **축소되어** 보임
* 사용자가 **확대/스크롤**해야 함

---

## 🧪 실전 예: 반응형 CSS와 함께 사용

```css
/* 화면 폭이 600px 이하일 때 글자 작게 */
@media (max-width: 600px) {
  body {
    font-size: 14px;
  }
}
```

이게 동작하려면 반드시 `<meta name="viewport" ...>`가 있어야 합니다.
