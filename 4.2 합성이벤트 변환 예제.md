

## ✅ JSX → JS 변환의 핵심 원리

JSX는 다음과 같이 변환됩니다:

```jsx
<MyComponent prop="value" />
```

⬇️ Babel이 변환

```js
React.createElement(MyComponent, { prop: "value" });
```

---

## ✅ 본문 예제 분석 (변환 전)

```jsx
<main style={{ padding: '20px' }}>
  <button onClick={handleClick}>클릭</button>

  <input
    type="text"
    placeholder="입력해보세요"
    onChange={handleChange}
    style={{ display: 'block', marginTop: '10px' }}
  />

  <div
    onMouseOver={handleMouseEnter}
    onMouseOut={handleMouseLeave}
    style={{ marginTop: '10px', padding: '10px', border: '1px solid gray' }}
  >
    마우스를 올려보세요
  </div>
</main>
```

---

## ✅ Babel이 변환한 후의 JavaScript 코드

JSX 전체는 다음과 같이 변환됩니다 (React 17+ 기준):

```js
import React from 'react';

const Main = (props) => {
  const handleClick = () => {
    props.logEvent('Click', '버튼 클릭됨');
  };

  const handleChange = (e) => {
    props.logEvent('Change', `입력값: ${e.target.value}`);
  };

  const handleMouseEnter = () => {
    props.logEvent('MouseOver', '마우스 진입');
  };

  const handleMouseLeave = () => {
    props.logEvent('MouseOut', '마우스 나감');
  };

  return React.createElement(
    'main',
    { style: { padding: '20px' } },
    React.createElement(
      'button',
      { onClick: handleClick },
      '클릭'
    ),
    React.createElement('input', {
      type: 'text',
      placeholder: '입력해보세요',
      onChange: handleChange,
      style: { display: 'block', marginTop: '10px' }
    }),
    React.createElement(
      'div',
      {
        onMouseOver: handleMouseEnter,
        onMouseOut: handleMouseLeave,
        style: {
          marginTop: '10px',
          padding: '10px',
          border: '1px solid gray'
        }
      },
      '마우스를 올려보세요'
    )
  );
};

export default Main;
```

## ✅ 각 JSX → JS 대응 표

| JSX 표현                              | JS 표현 (변환 후)                                                 |
| ----------------------------------- | ------------------------------------------------------------ |
| `<main style={...}>...</main>`      | `React.createElement('main', { style: {...} }, ...children)` |
| `<button onClick={fn}>텍스트</button>` | `React.createElement('button', { onClick: fn }, '텍스트')`      |
| `<input ... />`                     | `React.createElement('input', { ... })`                      |
| `<div onMouseOver=...>...</div>`    | `React.createElement('div', { onMouseOver: fn }, '...')`     |

---

## ✅ 주의: JSX는 결국 JS 함수 호출

JSX는 \*\*문법적 설탕(syntactic sugar)\*\*일 뿐이고,
실제로는 **`React.createElement(...)`를 호출하는 함수형 코드로 바뀌는 것**입니다.

---

## ✅ 추가 정보

| 항목                                             | 설명                                                          |
| ---------------------------------------------- | ----------------------------------------------------------- |
| `React.createElement(tag, props, ...children)` | React Element 객체 생성                                         |
| 변환 시점                                          | 개발 중 Babel, Vite, Webpack 등에서 자동 변환                         |
| 실행 시점                                          | `ReactDOM.createRoot(...).render(...)`가 이 Element를 DOM에 반영함 |
