## 🧠 개념 정리

### 🔹 `React.Suspense`란?

`React.Suspense`는 **비동기적으로 로딩되는 컴포넌트(주로 `lazy()`로 동적 import한 컴포넌트)** 를 감싸면서 **로딩 중 UI(fallback)를 보여주는 기능**입니다.

```jsx
import React, { Suspense, lazy } from 'react';

const MyComponent = lazy(() => import('./MyComponent'));

function App() {
  return (
    <Suspense fallback={<div>Loading...</div>}>
      <MyComponent />
    </Suspense>
  );
}
```

---

## 🚦 React Router에서의 `Suspense` 사용

### 🔸 언제 필요한가?

* `react-router-dom` v6부터는 `lazy()`를 통한 라우트 수준의 **동적 import**를 권장합니다.
* 이때 비동기로 로딩되는 라우트를 처리하기 위해 `Suspense`가 필요합니다.
* **라우트가 로딩되는 동안 보여줄 UI를 `fallback`으로 설정**합니다.

---

## 🧩 구성 예시

### 📁 구조

```
src/
  App.jsx
  routes/
    Home.jsx
    About.jsx
```

### 📄 코드 예시

```jsx
// App.jsx
import React, { Suspense, lazy } from 'react';
import { BrowserRouter, Routes, Route } from 'react-router-dom';

// 동적 import
const Home = lazy(() => import('./routes/Home'));
const About = lazy(() => import('./routes/About'));

function App() {
  return (
    <BrowserRouter>
      {/* Suspense로 Routes를 감쌈 */}
      <Suspense fallback={<div>Loading page...</div>}>
        <Routes>
          <Route path="/" element={<Home />} />
          <Route path="/about" element={<About />} />
        </Routes>
      </Suspense>
    </BrowserRouter>
  );
}

export default App;
```

---

## 🧪 동작 방식

### `lazy()` + `Suspense`의 흐름

1. 라우터가 `<Route path="/about" ... />`를 만나면,
2. `About.jsx` 모듈은 **동적으로 import** 됩니다.
3. 로딩 중에는 `Suspense`의 `fallback`이 렌더링됩니다.
4. 모듈 로딩이 완료되면 해당 컴포넌트를 렌더링합니다.

## 📝 주의 사항

| 항목                                       | 설명                                                          |
| ---------------------------------------- | ----------------------------------------------------------- |
| ❗ **`Suspense`는 반드시 `lazy` 컴포넌트를 감싸야 함** | 그렇지 않으면 fallback이 동작하지 않음                                   |
| 💡 **`fallback`은 필수 props**              | 컴포넌트 로딩 중 보여줄 UI                                            |
| ✅ **중첩 가능**                              | 라우트 전체를 감싸는 큰 `Suspense`, 특정 페이지에만 적용하는 작은 `Suspense` 모두 가능 |
| ⛔ SSR 사용 시 제약 존재 (2025년 기준)\*\*          | `React.Suspense`는 SSR 환경에서 제한적 지원 (Next.js는 자체 지원 방식 있음)    |

---

## 🎨 실전 응용: 중첩 라우트에서도 사용 가능

```jsx
<Route path="dashboard" element={
  <Suspense fallback={<div>Loading dashboard...</div>}>
    <Dashboard />
  </Suspense>
}>
  <Route path="analytics" element={<Analytics />} />
  <Route path="reports" element={<Reports />} />
</Route>
```

* 위와 같이 특정 라우트만 개별적으로 `Suspense`로 감쌀 수 있습니다.

---

## 🆚 `React.lazy` 없이 쓸 수 있나?

`React.Suspense`는 기본적으로 `lazy()` 또는 `defer()`와 같은 **비동기 로딩을 수반하는 컴포넌트**를 감쌀 때만 의미가 있습니다.
정적 import를 사용하는 컴포넌트는 Suspense에 감싸도 아무 효과가 없습니다.

## 🔧 Vite + React Router 사용 시

> `vite`에서는 코드 스플리팅이 자동으로 적용되므로, `lazy()`와 `Suspense`를 통해 페이지 단위로 번들을 나누는 것이 성능상 유리합니다.

```jsx
const Home = lazy(() => import('./pages/Home'));
const About = lazy(() => import('./pages/About'));
```

## 📚 결론

| 항목       | 설명                                               |
| -------- | ------------------------------------------------ |
| 목적       | **라우트를 코드 스플리팅할 때 로딩 상태를 처리하기 위해 사용**            |
| 필요 요소    | `React.lazy()`로 동적 import, `React.Suspense`로 감싸기 |

| 위치       | 일반적으로 `<Routes>`를 감싸지만, 특정 `<Route>`만 감쌀 수도 있음   |
