# 🔖 `<nav>` 태그란?

> **`<nav>`** 는 HTML5에서 도입된 **시맨틱(sementic)** 태그로,
> **웹사이트의 주요 내비게이션 링크 영역**을 명시적으로 나타냅니다.

```html
<nav>
  <a href="/">Home</a>
  <a href="/about">About</a>
  <a href="/contact">Contact</a>
</nav>
```

---

## ✅ 목적

* 사용자와 검색 엔진이 **내비게이션 영역**을 명확하게 식별할 수 있도록 함
* 보통 **사이트 메뉴, 상단 네비게이션 바, 사이드바 메뉴, 바닥글 링크 모음 등**에 사용

---

## 📘 시맨틱 의미란?

HTML 요소가 **"어떤 역할을 하는지"** 브라우저와 보조 기술(스크린 리더 등)에게 **의미적으로 전달**하는 것.

| 태그         | 의미                |
| ---------- | ----------------- |
| `<nav>`    | 주요 내비게이션 링크 모음    |
| `<header>` | 페이지나 섹션의 머리말      |
| `<main>`   | 본문 콘텐츠            |
| `<aside>`  | 부가 정보(광고, 사이드바 등) |
| `<footer>` | 하단 푸터 정보          |

---

## 🧠 `<nav>` vs `<div>`

| 항목     | `<nav>`       | `<div>`    |
| ------ | ------------- | ---------- |
| 의미     | 내비게이션         | 의미 없음      |
| 접근성    | 스크린 리더가 인식    | 없음         |
| SEO 영향 | 긍정적           | 없음         |
| 추천 용도  | 사이트 메뉴, 경로 안내 | 단순 레이아웃 구성 |

> ✅ `<nav>`는 구조와 역할을 브라우저, 검색엔진, 보조기술에 **명확하게 알리는 용도**입니다.

---

## 🧪 실전 예시

### 1. 상단 내비게이션

```html
<header>
  <nav>
    <ul>
      <li><a href="/">Home</a></li>
      <li><a href="/products">Products</a></li>
      <li><a href="/about">About</a></li>
    </ul>
  </nav>
</header>
```

### 2. 사이드바

```html
<aside>
  <nav>
    <ul>
      <li><a href="/faq">FAQ</a></li>
      <li><a href="/support">Support</a></li>
    </ul>
  </nav>
</aside>
```

## 🔍 사용 시 주의점

| 항목                        | 설명                                 |
| ------------------------- | ---------------------------------- |
| ✅ 한 페이지에 여러 개 사용 가능       | 예: 상단, 사이드, 푸터 등                   |
| ❌ 모든 링크 그룹에 사용하면 안 됨      | **핵심 내비게이션 링크**에만 사용하는 것이 시맨틱하게 적절 |
| ✅ `aria-label`로 명확히 구분 가능 | 여러 `<nav>` 구분이 필요한 경우              |

```html
<nav aria-label="Main navigation">
<nav aria-label="Footer navigation">
```

---

## 👨‍🦯 접근성(A11y) 관점

| 기능           | 설명                            |
| ------------ | ----------------------------- |
| 스크린 리더 지원    | `<nav>` 영역을 "내비게이션"으로 인식하고 알림 |
| `aria-label` | 내비게이션 목적을 명확히 지정 가능           |
| 키보드 탐색       | 내비게이션 영역은 탐색 시 중요한 역할을 함      |
