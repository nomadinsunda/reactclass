# `<NavLink>`란?

React Router의 `<NavLink>`는 **현재 URL과 자신이 가리키는 경로의 관계를 인식할 수 있는 네비게이션 링크 컴포넌트**입니다.

기본적인 페이지 이동 기능은 `<Link>`와 같지만, `<NavLink>`에는 중요한 기능이 하나 더 있습니다.

> **현재 URL이 자신의 `to` 경로와 일치하는지를 판단하여 `isActive` 상태를 제공한다.**

개념적으로 비교하면 다음과 같습니다.

```text
<Link>
    ↓
경로 이동


<NavLink>
    ↓
경로 이동
    +
현재 경로와의 일치 여부 판단
```

따라서 `<NavLink>`는 단순한 링크보다는 **현재 사용자가 어느 메뉴에 위치하고 있는지를 표시해야 하는 UI**에서 특히 유용합니다.

```jsx
import { NavLink } from 'react-router-dom';

<NavLink to="/about">
  About
</NavLink>
```

---

# 1. 왜 `<NavLink>`가 필요한가?

다음과 같은 네비게이션 메뉴가 있다고 생각해 봅시다.

```text
Home    About    Contact
          ↑
       현재 위치
```

현재 URL이 `/about`이라면 사용자는 메뉴를 통해 자신이 현재 **About 페이지에 있다는 사실**을 알 수 있어야 합니다.

예를 들어 다음과 같이 표현할 수 있습니다.

```text
Home    [ About ]    Contact
           ACTIVE
```

`<Link>`도 `/about`으로 이동할 수 있습니다.

```jsx
<Link to="/about">
  About
</Link>
```

하지만 `<Link>` 자체의 핵심 역할은 **네비게이션**입니다.

반면 `<NavLink>`는 네비게이션 기능에 더해 현재 location과 자신의 `to`를 비교하고, 그 결과를 상태로 제공합니다.

```text
현재 location

    /about
       │
       ▼
┌────────────────────┐
│    React Router    │
└─────────┬──────────┘
          │
          │ 현재 경로와 to 비교
          ▼
<NavLink to="/about">
          │
          ▼
    isActive = true
```

그래서 Navbar, Sidebar, Tab처럼 **현재 위치를 시각적으로 표현해야 하는 링크**에 적합합니다.

---

# 2. 기본 사용법

가장 기본적인 형태는 다음과 같습니다.

```jsx
<NavLink to="/home">
  Home
</NavLink>
```

`<NavLink>`는 브라우저에서 `<a>` 엘리먼트를 기반으로 렌더링됩니다.

개념적으로 보면 다음과 같습니다.

```html
<a href="/home">
  Home
</a>
```

하지만 일반적인 `<a>` 링크와 중요한 차이가 있습니다.

일반 `<a>`의 기본 동작은 브라우저가 새로운 URL의 Document를 요청하는 것이지만, React Router 안에서 `<NavLink>`를 사용하면 클릭 이벤트를 React Router가 처리하여 **SPA 방식의 클라이언트 측 네비게이션**을 수행합니다.

즉,

```text
사용자 클릭
    │
    ▼
<NavLink>
    │
    ▼
React Router
    │
    ├─ URL 변경
    ├─ location 갱신
    └─ 새로운 Route 렌더링
```

일반적인 SPA 네비게이션에서는 페이지 전체 Document를 다시 요청하지 않습니다.

# 3. 핵심 개념: `isActive`

`<NavLink>`를 이해할 때 가장 중요한 값은 `isActive`입니다.

```jsx
<NavLink
  to="/about"
  className={({ isActive }) =>
    isActive ? 'nav-link active' : 'nav-link'
  }
>
  About
</NavLink>
```

여기서 중요한 부분은 `className`에 단순 문자열이 아니라 **함수**를 전달했다는 것입니다.

```jsx
({ isActive }) => ...
```

React Router는 이 함수를 호출하면서 현재 `<NavLink>`의 상태를 전달합니다.

현재 URL이 `/about`이라고 해봅시다.

```text
현재 URL
/about

       ↕ 비교

to
/about

       ↓

isActive = true
```

따라서 다음 코드의 결과는

```jsx
isActive
  ? 'nav-link active'
  : 'nav-link'
```

다음과 같습니다.

```text
nav-link active
```

반대로 현재 URL이 `/contact`라면

```text
현재 URL
/contact

       ↕ 비교

to
/about

       ↓

isActive = false
```

결과는 다음과 같습니다.

```text
nav-link
```

즉, `isActive`는 쉽게 말하면

> **"이 링크가 현재 사용자의 위치를 나타내는 링크인가?"**

를 나타내는 boolean 값입니다.

---

# 4. `className`으로 활성 메뉴 표현하기

실무에서 가장 일반적인 사용 방식은 `className`을 함수로 사용하는 것입니다.

```jsx
<NavLink
  to="/about"
  className={({ isActive }) =>
    isActive ? 'nav-link active' : 'nav-link'
  }
>
  About
</NavLink>
```

CSS는 다음처럼 작성할 수 있습니다.

```css
.nav-link {
  color: gray;
  text-decoration: none;
}

.nav-link.active {
  color: blue;
  font-weight: bold;
}
```

현재 URL이 `/about`이면

```text
/about
   │
   ▼
isActive = true
   │
   ▼
className="nav-link active"
   │
   ▼
About 메뉴 강조
```

와 같은 흐름으로 동작합니다.

중요한 것은 `<NavLink>`가 직접 "파란색으로 만들어라"라고 결정하는 것이 아니라는 점입니다.

`<NavLink>`는

```text
현재 링크가 Active인가?
```

라는 **상태 정보**를 제공하고,

```text
Active일 때 어떤 UI를 보여줄 것인가?
```

는 개발자가 결정합니다.

---

# 5. `style`도 함수로 사용할 수 있다

`className`뿐만 아니라 `style`에도 함수를 전달할 수 있습니다.

```jsx
<NavLink
  to="/about"
  style={({ isActive }) => ({
    fontWeight: isActive ? 'bold' : 'normal',
    color: isActive ? 'red' : 'black',
  })}
>
  About
</NavLink>
```

현재 링크가 활성 상태라면 결과는 개념적으로 다음과 같습니다.

```jsx
{
  fontWeight: 'bold',
  color: 'red'
}
```

비활성 상태라면

```jsx
{
  fontWeight: 'normal',
  color: 'black'
}
```

이 됩니다.

따라서 핵심 관계는 다음과 같습니다.

```text
NavLink
   │
   ▼
isActive
   │
   ▼
개발자가 UI 결정
   │
   ├─ className
   └─ style
```

---

# 6. `children`도 함수로 사용할 수 있다

`<NavLink>`의 상태는 `className`과 `style`에서만 사용할 수 있는 것이 아닙니다.

`children`에도 함수를 전달할 수 있습니다.

```jsx
<NavLink to="/about">
  {({ isActive }) => (
    <span>
      {isActive ? '● ' : ''}
      About
    </span>
  )}
</NavLink>
```

현재 URL이 `/about`이면

```text
● About
```

처럼 표시할 수 있습니다.

즉, `<NavLink>`의 상태를 이용하면 단순한 색상 변경뿐만 아니라 아이콘, Badge, 텍스트 등 **링크 내부 UI 자체를 변경하는 것도 가능**합니다.

# 7. `isActive`와 `isPending`

`<NavLink>`의 render prop에서는 여러 상태를 받을 수 있습니다.

그중 가장 대표적인 것이 `isActive`와 `isPending`입니다.

| 상태          | 의미                                      |
| ----------- | --------------------------------------- |
| `isActive`  | 현재 location이 링크의 경로와 일치하는가              |
| `isPending` | 이동하려는 pending location이 이 링크의 경로와 일치하는가 |

예를 들어 다음처럼 사용할 수 있습니다.

```jsx
<NavLink
  to="/users"
  className={({ isActive, isPending }) => {
    if (isPending) return 'pending';
    if (isActive) return 'active';

    return '';
  }}
>
  Users
</NavLink>
```

개념적으로 보면

```text
<NavLink to="/users">
        │
        ├─ 현재 위치인가?
        │       ↓
        │   isActive
        │
        └─ 지금 이쪽으로 이동 중인가?
                ↓
            isPending
```

입니다.

다만 중요한 점이 있습니다.

> `isPending`은 React Router의 **Framework Mode와 Data Mode에서 사용할 수 있는 상태**입니다.

단순한 Declarative Mode의 `<BrowserRouter>` 기반 애플리케이션을 설명할 때는 `isActive`를 먼저 이해하는 것이 좋습니다.

---

# 8. `<NavLink>`의 내부 동작 흐름

다음과 같은 코드가 있다고 하겠습니다.

```jsx
<NavLink to="/about">
  About
</NavLink>
```

현재 URL도 `/about`이라면 개념적인 흐름은 다음과 같습니다.

```text
Browser URL
   │
   │ /about
   ▼
Router
   │
   │ 현재 location 관리
   ▼
NavLink
   │
   │ 현재 location과
   │ 자신의 to 비교
   ▼
경로 매칭
   │
   ├─ Match
   │    └─ isActive = true
   │
   └─ No Match
        └─ isActive = false
   │
   ▼
className / style / children
   │
   ▼
<a> 기반 UI 렌더링
```

따라서 `<NavLink>`의 핵심 동작을 압축하면 다음과 같습니다.

```text
현재 location
      │
      ▼
     to
      │
      ▼
 경로 매칭
      │
      ▼
  isActive
      │
      ▼
UI 상태 결정
```

이것이 `<NavLink>`의 가장 중요한 내부 개념입니다.

# 9. `end` — 어디까지 경로가 일치해야 하는가?

다음과 같은 링크가 있다고 하겠습니다.

```jsx
<NavLink to="/about">
  About
</NavLink>
```

기본적으로 `/about`뿐 아니라 `/about`의 하위 경로에서도 활성 상태가 될 수 있습니다.

```text
to="/about"

현재 URL

/about
    → Active

/about/team
    → Active

/about/company
    → Active
```

이는 `<NavLink>`가 기본적으로 링크의 경로가 현재 URL의 **앞부분과 일치하는 경우**도 활성 경로로 판단하기 때문입니다.

그런데 `/about`에서만 정확하게 활성화하고 싶을 수도 있습니다.

이때 `end`를 사용합니다.

```jsx
<NavLink to="/about" end>
  About
</NavLink>
```

결과는 다음과 같습니다.

```text
to="/about" + end

/about
    → Active

/about/team
    → Not Active

/about/company
    → Not Active
```

따라서 `end`는 다음과 같이 이해하면 쉽습니다.

> **"`to` 경로의 끝까지 일치해야 Active로 판단하라."**

# 10. `/`는 특별한 경우다

루트 경로 `/`는 다른 경로와 조금 다르게 취급됩니다.

논리적으로 생각하면 모든 URL은 `/`로 시작합니다.

```text
/
/about
/contact
/users/10
```

그래서 단순한 prefix matching만 사용한다면

```jsx
<NavLink to="/">
  Home
</NavLink>
```

이 모든 URL에서 활성 상태가 되어버릴 수 있습니다.

하지만 React Router는 이러한 문제를 방지하기 위해 **`to="/"`인 `<NavLink>`를 특별하게 처리합니다.**

즉, 현재 React Router에서는 루트 링크가 기본적으로 실제 루트 위치에서만 활성화됩니다.

```text
to="/"

/          → Active
/about     → Not Active
/contact   → Not Active
```

따라서 다음과 같이 작성하는 것도 가능합니다.

```jsx
<NavLink to="/">
  Home
</NavLink>
```

코드의 의도를 명시적으로 표현하고 싶다면 다음처럼 `end`를 붙여 작성해도 됩니다.

```jsx
<NavLink to="/" end>
  Home
</NavLink>
```

다만 중요한 것은

> **현재 React Router에서 `/`는 일반 경로와 다른 특별한 매칭 규칙을 가진다.**

는 점입니다.

따라서 "`/`에서는 반드시 `end`가 있어야 Home만 활성화된다"라고 설명하는 것은 정확하지 않습니다.

---

# 11. 활성 링크에는 `aria-current="page"`가 적용된다

`<NavLink>`에는 접근성 측면에서도 중요한 기능이 있습니다.

현재 링크가 active 상태가 되면 React Router는 해당 링크에

```html
aria-current="page"
```

를 적용합니다.

개념적으로 보면 다음과 같습니다.

```jsx
<NavLink to="/about">
  About
</NavLink>
```

현재 URL:

```text
/about
```

활성 상태가 되면 브라우저 DOM은 개념적으로 다음과 비슷한 형태가 됩니다.

```html
<a
  href="/about"
  aria-current="page"
>
  About
</a>
```

`aria-current="page"`는 스크린 리더 등의 보조 기술에게

> **"이 링크가 현재 페이지를 나타낸다."**

는 정보를 전달합니다.

따라서 `<NavLink>`는 단순히 CSS 스타일을 편리하게 만드는 컴포넌트가 아니라 **네비게이션의 현재 위치를 의미적으로 표현하는 역할**도 합니다.

# 12. `<Link>`와 `<NavLink>`의 차이

두 컴포넌트 모두 React Router의 클라이언트 측 네비게이션을 수행합니다.

가장 중요한 차이는 **현재 경로와의 관계를 UI에서 사용할 필요가 있는가**입니다.

| 항목                | `<Link>` | `<NavLink>`           |
| ----------------- | -------- | --------------------- |
| 기본 목적             | 경로 이동    | 경로 이동 + 현재 위치 표현      |
| SPA 네비게이션         | O        | O                     |
| Active 상태         | 직접 판단 필요 | `isActive` 제공         |
| Pending 상태        | 기본 목적 아님 | 지원되는 Router Mode에서 제공 |
| 상태 기반 `className` | 직접 구현    | 쉽게 구현 가능              |
| 상태 기반 `style`     | 직접 구현    | 쉽게 구현 가능              |
| `aria-current`    | 직접 처리    | Active일 때 자동 처리       |
| 대표 용도             | 일반 링크    | Navbar, Sidebar, Tab  |

선택 기준은 간단합니다.

```text
단순히 이동만 필요
        │
        ▼
      <Link>


현재 위치도 표현해야 함
        │
        ▼
    <NavLink>
```

# 13. 실전 예제: Navigation Menu

```jsx
import { NavLink } from 'react-router-dom';

function Navigation() {
  return (
    <nav>
      <NavLink
        to="/"
        className={({ isActive }) =>
          isActive ? 'nav-link active' : 'nav-link'
        }
      >
        Home
      </NavLink>

      <NavLink
        to="/about"
        className={({ isActive }) =>
          isActive ? 'nav-link active' : 'nav-link'
        }
      >
        About
      </NavLink>

      <NavLink
        to="/contact"
        className={({ isActive }) =>
          isActive ? 'nav-link active' : 'nav-link'
        }
      >
        Contact
      </NavLink>
    </nav>
  );
}

export default Navigation;
```

현재 URL이 `/about`이라면 각 링크의 상태는 개념적으로 다음과 같습니다.

```text
Home        About        Contact
 │            │             │
false        true          false
 │            │             │
 ▼            ▼             ▼
normal      ACTIVE        normal
```

따라서 사용자는 메뉴만 보고도 현재 자신이 About 페이지에 있다는 사실을 확인할 수 있습니다.

# 14. `<NavLink>`를 한 문장으로 정의하면

> **`<NavLink>`는 `<Link>`의 클라이언트 측 네비게이션 기능에 현재 location과 자신의 목적지 경로가 일치하는지를 판단하는 기능을 추가하여, Navbar·Sidebar·Tab과 같은 네비게이션 UI에서 현재 위치를 쉽게 표현할 수 있도록 만든 React Router의 링크 컴포넌트입니다.**

# 핵심 정리

| 항목             | 설명                                  |
| -------------- | ----------------------------------- |
| `<NavLink>`    | 현재 경로와 자신의 목적지 관계를 인식하는 링크          |
| `to`           | 이동할 목적지                             |
| `isActive`     | 현재 location이 링크와 일치하는지 나타내는 상태      |
| `isPending`    | 해당 링크로 이동하는 네비게이션이 pending 상태인지 나타냄 |
| `className`    | 상태에 따라 CSS 클래스 결정 가능                |
| `style`        | 상태에 따라 인라인 스타일 결정 가능                |
| `children`     | 상태에 따라 링크 내부 UI 변경 가능               |
| `end`          | `to` 경로의 끝까지 일치해야 Active로 판단        |
| `aria-current` | Active 링크에 `"page"`가 자동 적용          |
| 최종 렌더링         | `<a>` 엘리먼트 기반                       |
| 주요 용도          | Navbar, Sidebar, Tab 등의 현재 위치 표시    |

전체 구조를 하나의 흐름으로 압축하면 다음과 같습니다.

```text
       현재 location
             │
             ▼
        <NavLink>
       to="/about"
             │
             │ 경로 매칭
             ▼
      ┌─────────────┐
      │  isActive   │
      │ true / false│
      └──────┬──────┘
             │
       ┌─────┼─────┐
       ▼     ▼     ▼
 className  style  children
       │     │      │
       └─────┼──────┘
             ▼
       현재 메뉴 표현
```

결국 `<NavLink>`의 본질은

> **"스타일이 적용된 `<Link>`"가 아니라, "현재 URL과 자신의 목적지 경로 사이의 관계를 알고 있는 `<Link>`"**

라고 이해하는 것이 가장 정확합니다.
