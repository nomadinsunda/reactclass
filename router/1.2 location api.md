# 🌐 window.location

> `window.location`은 브라우저에서 **현재 페이지의 URL 정보를 읽거나 수정할 수 있는 내장 객체**입니다.
> 이 객체는 **`Location` 인터페이스**를 따르며, 전역 객체인 `window`의 속성으로 존재합니다.

```js
console.log(window.location);
```

---

## 📦 주요 속성과 메서드

### 🔑 주요 속성 (읽기/쓰기 가능)

| 속성         | 설명                       | 예시                                              |
| ---------- | ------------------------ | ----------------------------------------------- |
| `href`     | 전체 URL                   | `https://example.com:8080/path?query=1#section` |
| `protocol` | 프로토콜                     | `https:`                                        |
| `host`     | 호스트 (`hostname:port`)    | `example.com:8080`                              |
| `hostname` | 도메인만                     | `example.com`                                   |
| `port`     | 포트 번호                    | `8080`                                          |
| `pathname` | 경로 (슬래시 포함)              | `/path`                                         |
| `search`   | 쿼리 스트링                   | `?query=1`                                      |
| `hash`     | 해시 (앵커)                  | `#section`                                      |
| `origin`   | `protocol + '//' + host` | `https://example.com:8080`                      |

---

### 🔧 주요 메서드

| 메서드            | 설명                    | 특징                   |
| -------------- | --------------------- | -------------------- |
| `assign(url)`  | 새로운 페이지로 이동 (히스토리 추가) | 기존 기록 보존             |
| `replace(url)` | 현재 페이지를 새 URL로 교체     | 히스토리 덮어쓰기 (뒤로 가기 불가) |
| `reload()`     | 현재 페이지 새로고침           | 캐시 포함/무시 여부 설정 가능    |

---

## 🧪 예제

### 1. 현재 URL 정보 가져오기

```js
console.log(location.href);       // 전체 URL
console.log(location.pathname);   // "/products/42"
console.log(location.search);     // "?sort=asc&page=2"
console.log(location.hash);       // "#specs"
```

---

### 2. 페이지 이동

```js
location.assign('https://google.com');   // 새 URL로 이동 (뒤로 가기 가능)
location.replace('https://google.com');  // 현재 URL 대체 (뒤로 가기 불가)
```

---

### 3. 페이지 새로고침

```js
location.reload();               // 기본: 캐시 허용
location.reload(true);           // 캐시 무시 (구식, 최신 브라우저는 무시)
```

---

## 🧠 주의할 점

| 항목                | 설명                                                                                |
| ----------------- | --------------------------------------------------------------------------------- |
| 페이지 전환 시 서버 요청 발생 | `assign`, `replace`는 브라우저의 **정식 네비게이션**을 트리거함                                     |
| 보안 제한             | 일부 속성은 cross-origin 상황에서 읽을 수 없음                                                  |
| SPA 프레임워크에서는 주의   | React, Vue 등에서는 `window.location` 직접 조작보다 `history.pushState`나 `router.push()` 권장 |

---

## 🔍 `window.location` vs `document.location`

* **사실상 동일**: `document.location === window.location`은 `true`
* 하지만 관례상 **`window.location`** 또는 단축형 **`location`** 사용

## 🧾 요약

| 항목     | 설명                                               |
| ------ | ------------------------------------------------ |
| 정의     | 브라우저 주소창과 연동되는 URL 조작 API                        |
| 제공 주체  | 브라우저(Web API), `window` 객체의 속성                   |
| 사용 목적  | 현재 주소 읽기, 페이지 이동, 새로고침 등                         |
| 주요 속성  | `href`, `pathname`, `search`, `hash`, `origin` 등 |
| 주요 메서드 | `assign()`, `replace()`, `reload()`              |

## 📘 예: URL이 다음과 같을 때

```
https://example.com:3000/products?id=123#review
```

| 속성                  | 값                                                   |
| ------------------- | --------------------------------------------------- |
| `location.href`     | `"https://example.com:3000/products?id=123#review"` |
| `location.protocol` | `"https:"`                                          |
| `location.host`     | `"example.com:3000"`                                |
| `location.hostname` | `"example.com"`                                     |
| `location.port`     | `"3000"`                                            |
| `location.pathname` | `"/products"`                                       |
| `location.search`   | `"?id=123"`                                         |
| `location.hash`     | `"#review"`                                         |
| `location.origin`   | `"https://example.com:3000"`                        |
