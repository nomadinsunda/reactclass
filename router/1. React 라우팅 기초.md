# 📌 React 라우팅 기초: SPA, BrowserRouter, Routes

React 애플리케이션을 개발하다 보면, 페이지 전환이 필요한 순간이 반드시 찾아옵니다.
그럴 때마다 새로고침 없이 부드럽게 화면이 전환되는 **SPA(Single Page Application)** 구조는 굉장히 매력적입니다.
이번 챕터에서는 React 라우팅의 핵심 개념과 함께 `react-router-dom`을 이용한 **기본 라우팅 구조**를 정리해보겠습니다.

---

## 🧠 1. SPA란 무엇인가?

> **SPA (Single Page Application)**
>
> * 단 하나의 HTML 문서를 기반으로 동작하는 웹 애플리케이션
> * 페이지 전환 시 전체를 다시 로딩하지 않고, **필요한 부분만 JavaScript로 변경**

### 🔁 전통적인 MPA와의 비교

| 구분        | MPA (Multi Page Application) | SPA (Single Page Application) |
| --------- | ---------------------------- | ----------------------------- |
| 페이지 전환 방식 | HTML 문서 전체를 다시 요청            | 현재 페이지 내에서 JS로 변경             |
| 속도        | 느림 (전체 새로고침)                 | 빠름 (부분 변경)                    |
| 사용자 경험    | 브라우저가 깜빡거림                   | 부드러운 전환                       |
| 예시        | 네이버 뉴스, 구버전 쇼핑몰              | Gmail, Facebook, Instagram    |

> React는 SPA를 아주 잘 구현할 수 있는 프레임워크입니다. 하지만 URL에 따라 화면을 다르게 보여주기 위해선 별도의 **라우팅 도구**가 필요합니다.

---

## 🧭 2. React Router란?

`react-router-dom`은 React 애플리케이션에서 라우팅을 담당하는 가장 보편적인 라이브러리입니다.

```bash
npm install react-router-dom
```

React Router는 다음과 같은 기능을 제공합니다:

* URL에 따라 다른 컴포넌트 보여주기
* `<Link>`를 통한 클라이언트 사이드 내비게이션
* 동적 라우팅 (파라미터, 쿼리)
* 중첩 라우팅, 네스티드 라우팅
* 코드 분할 및 라우트 보호 등

---

### 📦 설치

```bash
npm install react-router-dom
```

## 🏗️ 3. 라우팅의 기본 구조

| 개념                                | 설명                                               |
| --------------------------------- | ------------------------------------------------ |
| **BrowserRouter**                 | 브라우저의 히스토리 API를 이용해 URL을 관리하는 라우터 컨테이너           |
| **Routes**                        | 여러 개의 `Route`를 그룹화하는 컨테이너                        |
| **Route**                         | 특정 경로에 어떤 컴포넌트를 렌더링할지를 정의                        |



### 3-1. `BrowserRouter`

브라우저의 **History API**를 활용하여 라우팅을 가능하게 해주는 컴포넌트입니다.
앱의 루트에 한 번만 감싸주면 됩니다.

```jsx
import { BrowserRouter } from 'react-router-dom';

function App() {
  return (
    <BrowserRouter>
      {/* 여기에 Routes 정의 */}
    </BrowserRouter>
  );
}
```

### 3-2. `Routes`와 `Route`

`Routes`는 여러 개의 `<Route />`를 감싸는 역할을 하며,
각 `<Route>`는 특정 경로(`path`)에 어떤 컴포넌트(`element`)를 렌더링할지 정의합니다.

```jsx
import { Routes, Route } from 'react-router-dom';
import Home from './pages/Home';
import About from './pages/About';

function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />
      </Routes>
    </BrowserRouter>
  );
}
```

### 3-3. `Link` vs `a` 태그

* `<a href="/about">About</a>`: 전체 페이지 새로고침 발생 ❌
* `<Link to="/about">About</Link>`: 페이지 새로고침 없이 전환 ⭕

```jsx
import { Link } from 'react-router-dom';

function Navbar() {
  return (
    <nav>
      <Link to="/">Home</Link>
      {' | '}
      <Link to="/about">About</Link>
    </nav>
  );
}
```

## 🔄 4. 전체 예시: 간단한 SPA 구성

```jsx
// App.jsx
import { BrowserRouter, Routes, Route } from 'react-router-dom';
import Home from './pages/Home';
import About from './pages/About';
import Navbar from './components/Navbar';

function App() {
  return (
    <BrowserRouter>
      <Navbar />
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />
      </Routes>
    </BrowserRouter>
  );
}
```

```jsx
// pages/Home.jsx
export default function Home() {
  return <h2>🏠 Home Page</h2>;
}
```

```jsx
// pages/About.jsx
export default function About() {
  return <h2>📄 About Page</h2>;
}
```

```jsx
// components/Navbar.jsx
import { Link } from 'react-router-dom';

export default function Navbar() {
  return (
    <header>
      <Link to="/">Home</Link> | <Link to="/about">About</Link>
    </header>
  );
}
```

## 📎 5. 핵심 정리

| 개념            | 설명                          |
| ------------- | --------------------------- |
| SPA           | 단일 페이지 앱, 새로고침 없이 화면 전환     |
| BrowserRouter | 라우터 설정의 루트 컴포넌트             |
| Routes        | 여러 Route들을 감싸는 컨테이너         |
| Route         | 특정 URL 경로에 컴포넌트를 매핑         |
| Link          | 페이지 새로고침 없이 이동 가능하게 하는 컴포넌트 |
